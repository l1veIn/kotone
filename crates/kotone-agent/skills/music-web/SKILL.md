# 在网页上放歌

歌在 Kotone 右侧栏的浏览器里放，不碰玩家电脑上的音乐软件。下面的内容 2026-11-21 在真网站上核对过；写着“未核实”的是还没机会看到（大多要登录后才看得到）。

## 用哪个网站

- 用附注里“放歌用”的那个网站（玩家在「设置 → 权限 → 放歌」里选的，默认网易云音乐）。
- 只有玩家这次明确说了用别的网站（“用 QQ 音乐放”），才用他说的。
- **不要自己换网站**：要登录、搜不到、没有版权、要会员，都留在这个网站上处理（见下面），
  照实写进总结，由主会话告诉玩家。玩家说“换个网站”才换。

## 步骤

1. `browser.open` 打开下面对应网站的**搜索网址**（歌名做网址编码，例如“晴天”是 `%E6%99%B4%E5%A4%A9`），再 `browser.snapshot`。
2. **要登录时**：四个网站的网页版**不登录都放不了歌**。看到这些就是没登录，不是没有这首歌：
   - 网易云：搜什么都是“找到 0 首”，结果链接指向 `/login`；
   - QQ 音乐：一打开就弹“QQ登录 / 微信登录 · 扫码登录”；
   - 酷狗：歌曲页弹出“手机扫码，安全登录酷狗”，点了播放没有声音；
   - 酷我：弹“付费内容提醒”（不收费的歌也这样）。

   这时调用 `browser.handover`，理由写“{网站名}要登录：在右边用手机 App 扫码”。玩家登好以后接着做。
   玩家点了“好了”页面却还是没登录：再 `browser.handover` 一次，说明还没登上、请他再扫一次。
3. 在结果里找歌名和歌手都对得上的第一条，按下面各网站的写法开始播放。
   **登录了还是搜不到**（或者结果里没有对得上的）：不换网站，停下来写总结，例如“网易云音乐上没搜到《雨爱》（杨丞琳）”，
   并建议玩家换一首、或者说一声换个网站。
4. **确认在放**：`browser.snapshot` 看播放条（进度在走、按钮变成暂停），或者结束后由主会话用 `music now` 查。
5. 没放起来时看页面写了什么，照实写进总结：
   - “VIP单曲 / 开通VIP畅听 / 付费内容”：要会员，玩家不是会员只能试听或放不了；
   - 网易云上周杰伦这类歌没有版权；
   - “去客户端播放 / 点击打开客户端”：**不要点**（会尝试拉起玩家电脑上的客户端，Kotone 会拦下，白费一步）。

   不换网站，总结里写清原因，建议玩家换一首、或者说一声换个网站。
6. 总结里写清：在哪个网站、放的是哪首（歌名 - 歌手）。

之后玩家说暂停、继续、下一首、这首歌叫什么，主会话直接用 `music` 做，不用再交给后台。

## 网易云音乐（music.163.com）

- 搜索网址：`https://music.163.com/#/search/m/?s=<歌名>&type=1`（不登录时只显示“找到 0 首”；登录后的结果页**未核实**）。
- 页面内容在一个叫 `contentFrame` 的内嵌页里，`browser.snapshot` 会一起读出来。
- 歌曲页 `https://music.163.com/#/song?id=<编号>` 上有“播放”按钮；不登录点了没反应。
- 不少歌是“VIP单曲”；周杰伦等歌没有版权。
- 底部播放条的“下一首”是 `a.nxt`（title“下一首(ctrl+→)”）。
- 登录：右上角“登录”，可以用网易云音乐 App 扫码。

## QQ 音乐（y.qq.com）

- 搜索网址：`https://y.qq.com/n/ryqq/search?w=<歌名>&t=song`（会跳到 `ryqq_v2/search`）。
- 不登录一打开就弹扫码登录（QQ / 微信）。
- 登录后的结果页、播放条、“下一首”按钮：**未核实**。

## 酷狗（kugou.com）

- 搜索网址：`https://www.kugou.com/yy/html/search.html#searchType=song&searchKeyWord=<歌名>`。
- 结果每行一个“歌手 - 歌名”的链接，点它进歌曲页（`https://www.kugou.com/mixsong/....html`）并加入播放队列。
- 歌曲页播放条：播放 / 暂停 `#toggle`，上一首 `#prev`，下一首 `#next`。
- 不登录：弹扫码登录，点播放没有声音（不是会员歌也一样）。登录后能不能放：**未核实**。

## 酷我（kuwo.cn）

- 搜索网址：`https://www.kuwo.cn/search/list?key=<歌名>`。
- 结果里歌名是链接 `/play_detail/<编号>`，列表上方有“播放全部”。行里的有些图标是 MV（会跳到 `/mvplay/...`），不要点。
- 歌曲页有“立即播放”。
- 不登录：弹“付费内容提醒：该歌曲为付费内容，请下载酷我音乐客户端后付费收听”，不收费的歌也一样。登录后能不能放：**未核实**。
- 底部播放条的“下一首”是 `div.next`（title“下一首”）。
