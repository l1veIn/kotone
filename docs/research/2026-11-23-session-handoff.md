## 二、这轮做了什么（ADR 035）

玩家原话：“琴音，帮我查一下这把游戏选手们的战绩，告诉我对面谁是突破口”“帮我记录一下对面的召唤师技能。谁没闪？帮我发在聊天框”。

- **新 crate `crates/kotone-lol`**：
  - `auth`：从 `LeagueClientUx.exe` 的命令行读端口和令牌；
  - `client`：LCU 和局内接口（2999），只发 GET、只连 127.0.0.1；
  - `gamedata`：客户端自带的中文资料，有英雄的称号、名字和英文 id，召唤师技能的冷却，装备，海克斯，队列；
  - `live`：局内数据；
  - `history`：战绩、隐私、段位；
  - `scout`：统计和突破口；
  - `spells`：手动计时，模式急速加明朗之靴；
  - `text`：写成给她看的文字；
  - 例子 `examples/render_probe.rs`：用探测结果离线跑一遍三个工具。
- **`kotone-platform-windows/src/process_cmdline.rs`**：不提权读别的进程的命令行。
- **工具**（`crates/kotone-agent/src/lol.rs`，主会话用，马上返回）：
  - `lol.match`：这局的样子，以及谁没闪、谁没带闪；
  - `lol.spell`：玩家说“阿狸闪了”就记下，返回 `chat`，例如“阿狸 闪 14:32好”；
  - `lol.scout`：10 个人的战绩和突破口。
- **桌面端 `apps/desktop/src-tauri/src/lol.rs`**：
  - 客户端开着时每 2 秒看一次对局阶段；
  - 进加载界面就查战绩，同时 2 个、每人 20 局；
  - 这局结束时清掉技能记录。
- **设置** `lol.enabled`（默认开）；“游戏列表 → 英雄联盟”配置页有开关和风险提示。
- **玩家改了三处**：
  - 不用那么谨慎，加提示就行；
  - 冷却先试接口；
  - 查全部模式，隐藏战绩照读并标出来。
- **检查**：
  - 工作区 clippy 没有警告，fmt 通过；
  - 改到的 crate 的测试全过（kotone-lol 23 个）；
  - svelte-check 0 错误；Playwright 144 个全过。

**实测（只读，没按键）**：

- 训练模式：不提权读得到命令行；国服不写 lockfile；局内接口 26 个路径都没有冷却字段；`championName` 是称号（“刀锋舞者”）；海斗队列 id 是 2400。
- 一局真人海斗：进了对局后，10 个人的 puuid、英雄、召唤师技能、战绩都拿得到，每人约 1.3 秒；用真实数据跑三个工具的文字，结果正常。

## 七、第三轮（2026-11-24）：定下“Kotone 是什么”，插件重构只写了计划

**定下来的**（ADR 038，Accepted 方向）：

- Kotone 是一个陪你打游戏的角色，本事都装在插件里，人和外部 Agent 用同一套；
- 本体 = 她、感官和表达（含读聊天）、自动化、宿主；
- 插件照 MCP Apps：给她的文字和给页面的数据分开，只给页面用的工具不进她的清单，聊天里放页面的快照，点开在右侧栏；
- 界面上叫“插件”，写进了术语表；
- 语音识别只有一份，在本体；语音输入插件用它。

**没做的**：重构本身。玩家说这轮会话不做，先收尾、写计划。计划在 [`docs/plugin-refactor.md`](../plugin-refactor.md)：要达到什么（带基线数字）、8 个插件（英雄联盟是一个插件，战绩和网上的统计各一个数据开关）、契约、目录、7 步和每步的验收、风险。

### 工作方式

玩家原话：“如果下次进行某些长任务迭代，应该要求主会话不直接写代码，只采用子代理写代码。”

- **分工：** 主会话只做计划、写子代理的任务、看报告、读验证结果、`git commit -- <路径>`、写记录。代码全部交给子代理。

  - 单独编译、单独提交，并过这些检查：`cargo test`、`cargo clippy -- -D warnings`、`svelte-check`、Playwright。碰到语音、工具、英雄联盟的，加跑对应的真机脚本。

### 已知风险、没修的审查发现

审查一共 14 条：#1 由 `50593e57` 修，#3 #4 #10 #11 由 `013789e7` 修，#2 #5 #6 #7 #8 #9 #12 #14（和保留名 `saved`）由 `182fc8c4` 修；没修的是 #13。

- **#13 每个插件 App 的源是 127.0.0.1 的随机端口**：Kotone 下次启动时，同一个端口可能分给别的插件，后者就和前者同源，能读到前者存在 `localStorage` 里的东西。英雄联盟 App 不存东西，现在没影响；第三方的 App 可能存。修法以后定（例如每个插件记住自己的端口，或者端口换了主人时清掉那个源的存储）。
- **手改 `mcp.json` 加的服务器启动时不弹信任提示**：方案有意这样（见“要玩家定的”第 3 条）。
- **`cargo build` 不经 `tauri build` 会编进占位页**：英雄联盟 App 由 `tauri build` 的 `beforeBuildCommand` 先打包；直接 `cargo build` / `cargo run` 的桌面端里，英雄联盟的页面是占位页。发布路径没事；开发时先跑 `pnpm -C apps/desktop build:apps`。
- Tauri 在 WebView2 里把 `__TAURI_INTERNALS__` 也放进了 App 的 iframe，从 App 调 Kotone 的命令没有执行（`mcp_app_real.py` 查过）。现在是安全的一边，Tauri 或 WebView2 升级后要再查一次。
- 第三方 App 的 CSP 挡了本机和私网地址，挡不了解析到本机的公网域名（DNS 重绑定），要靠本机服务自己查 `Host` / `Origin`。
- 转到后台的工具，费用只记到对话、没记到发起的那一轮。
- `plugins/lol` 的 `rust-version` 还写着 1.77.2，实际要 1.88（`kotone-mcp`）以上；调高时 clippy 会要求把 7 处 `map_or(true, …)` 改成 `is_none_or`。
- CommunityDragon 从这台机器 `curl` 一次 0.5 秒、一次 17 秒；国服玩家那里要是很慢，客户端没开时页面先显示占位（ADR 039 D6“什么事实会让我们改主意”）。

### 我定的（都写进了对应 ADR 的实施记录，标“主会话定的，玩家可以改”）

- **发到游戏（041）**：入口收截止时间，等锁、逐行都看它，结果总是真的——没照子代理“工具服务先超时、字照发”的建议（外部 Agent 看到超时会重试，队友收到两遍）。语音输入把要回去的窗口交给入口，入口拿到锁再切回（改了 D5）。插件不能直接打字注入（改了 038）。对局里不归插件（第 1 期的游戏配置就是 LeagueAkari 对局里的做法，改了 D3）。“在客户端里发聊天”单独一个开关、默认开、带风险提示和出处。她发话时 Kotone 在前台照旧说“先切到客户端”；语音输入频道停在“所有人”进了选英雄、关了自动发送的人在选英雄 / 房间里——都不发、说清楚。
- **`ui.open`**：外部 Agent 调不加询问（工具服务没有询问机制，ADR 014 第 5 节）；评估那句“外部 Agent 调要经权限”和 ADR 014 冲突，认 ADR 014。
- **同传**：在线识别听得懂外语就给同传用，不要求下载 SenseVoice（页面写明上传、每句计费，PRIVACY.md 加一条）；X-ASR 等听不懂外语的另用 SenseVoice；停止本地识别时同传一起停、她说一句。
- **热键（040）**：页面叫“热键”不叫“快捷键”（术语表 v2）。冲突照旧不让存。要“听一句”的命令识别没启动时照“说话”键的被动提示、不吞键（没照子代理“一直吞键”）。Esc 组合不再生效、表里写原因。打开页面的热键把 Kotone 拿到前面，独占全屏时不拿。调工具成功弹幕一行、不出声。“发到游戏聊天”放在“调一个工具”最上面。运行自动化 / 调工具 / 打开页面不用先启动识别。她或外部 Agent 加的要确认的热键，玩家在「设置 → 热键」点确认才生效。一键喊话先做四条、队伍频道、不带默认键。第 2、3 期一起发版。
