# 0.1.x 到 0.2.0 过渡验证报告

日期：2026-11-19。范围与发布门槛见 [ADR 027](../adr/027-0.2-upgrade-transition.md)。

## 工作树和数据边界

- 0.1.14 维护线 `codex/maint-0.1.14` 从 `v0.1.13` 建立。0.2.0 在 `claude/kotone-agent` 上继承已合入 #18/#20 的基础提交 `208534b4`。
- 用只读无缓存请求核对 COS 和 GitHub 的两个旧更新地址，均返回 0.1.13。
- 正式的 0.1.13 不认识 `KOTONE_HOME`，且始终注册单实例。不能在玩家账号下用原包完成安装测试。用于本机的 0.1.13 对照源码仅加隔离补丁 `93df9176`（测试工作树 `ed4ec2d3`），不是发布制品。
- 两个诊断包都是 0.1.13，包含热键、运行模式、活动游戏、识别模型和历史元数据。包里缺少完整 `config.json`、游戏配置、等待中的提醒和音频。测试只读取 `manifest.json`、`runtime.json` 的白名单字段，重建一份本地 X-ASR 配置和一份讯飞远程识别配置。仓库只留测试脚本和结果。完整的社群匿名配置样本仍待补。

## 升级和降级

- 运行 `scripts/manual-e2e/upgrade_transition.py`，使用三个版本的 Rust 数据加载代码，输入 1 份合成和 2 份由诊断快照重建的夹具，隔离路径在工作树的 `target/upgrade-e2e/`。
- 三份夹具都通过 0.1.13 → 0.1.14 → 0.2.0 → 0.1.14 写盘再读取，并由 0.1.13 再读取配置。对照了录音和提醒热键、交互模式、游戏、麦克风、识别模型、VAD、音效及发送参数。独立写入琴音呼叫键和连接后，再用旧版本读取，原提醒设置仍然一致。
- 对每份夹具保留两条分支。一条用 0.1.14 删除 Dota 2 后升级与降级，一条不删除。结果分别为 0 份和 1 份配置。两支线的配置文件与图标逐字节一致。设置降音量后，两次切换仍为 `true`。
- 核心单测用隔离数据验证原有提醒的 ID、交付方式与到期时间，将原来的待触发提醒在原到期点只播一次，并保留历史。原来的 `reminders.json` 保留给 0.1.x。如果 0.2 已经播过旧提醒，立刻退到 0.1.13 仍可能在旧调度器的两分钟宽限内重播。0.2 新建提醒保存在新调度文件，0.1.13 无法读取。
- 0.2 的 Rust 工作区 941 项通过，23 项忽略。其中核心 271 项、编排集成 84 项、桌面 72 项通过。Rust 格式与 Clippy 通过，仍见既有 Windows 链接警告 LNK4098。97 项浏览器测试通过，覆盖继续用语音输入法、原提醒入口，以及显式启用琴音后保留录音热键、ASR、活动游戏和旧提醒连接。前端类型检查和 8 项发布脚本测试通过。生产 JavaScript 依赖和 Rust 发布审计退出码 0，Rust 审计有 15 条允许警告。
- 上述不是原发布包实装链。实际覆盖/卸载/降级、真实语音识别后打进游戏聊天、低层钩子的物理 `~` 传递，要在专用 Windows 用户或虚拟机按 [复测步骤](../../scripts/manual-e2e/README.md#跨版本过渡)补测。

## 启动、内存与包体

0.1.13 的正式 GitHub x64 NSIS 包为 **14,784,612 字节**。本机下载后与发布方的 SHA256SUMS 对上（`1292c8ec5553ba2f7da08d700bda0ccbf8e1f47c322a9fec836096c7ad0ab17b`），Windows Authenticode 为 NotSigned。[0.1.13 发布](https://github.com/l1veIn/kotone/releases/tag/v0.1.13)

0.1.14 的本地优化构建生成 x64 NSIS 安装包 **14,743,130 字节**，比 0.1.13 正式包小 41,482 字节。正式 0.1.13 未以原包在玩家账号运行。

同机运行 0.1.13 隔离构建 `ed4ec2d3` 和 0.2.0 候选 `4d0ccfdd`，均为 x64 优化构建。环境为 Windows 11 Pro 10.0.26200、Ryzen 7 9800X3D、31.19 GiB 内存、WebView2 157.0.4341.60、Rust 1.98.0、Node 24.18.1。

两个版本交替各跑三次。每次新建应用数据和 WebView2 目录，保留系统文件缓存。首屏指启动到设置页面就绪，旧版是语音输入首页，新版是升级说明。新版三次都能选「继续只用语音输入法」并进入输入首页。等 8 秒后间隔 0.5 秒采五次工作集，取中位。进程树合计含 WebView2，共享页可能重复计数。本机代理拦下旧版每次两个更新请求，新版三次均未向代理发更新请求。

| 主进程闲置工作集中位数 | 61.26 MiB | 75.39 MiB | +14.13 MiB |

首屏原始采样为旧版 687、767、621 ms，新版 795、854、723 ms。0.2.0 候选比正式 0.1.13 安装包大 4,517,758 字节（约 30.6%）。旧隔离 EXE SHA-256 是 `d1a22f9a22f66dfd868bb2ed559f105a51f804099ed0f6953d8ef3439825b09b`。本机原始结果为 `target/upgrade-bench-kuw1qw2b/results.json`。

## 发布前剩余验收

- **0.1.14**。已有自动化、三份配置往返和本地包验证。一份合成旧配置即可做剩余的隔离覆盖安装冒烟，核对旧录音键、识别设置和语音输入。正式发布流程需核对更新签名、清单和校验和。
- **0.2.0**。放量前补齐完整匿名配置、经 0.1.14 升到 0.2.0 的安装及回退、备份还原、真实游戏语音与物理按键、360 和火绒实测，并由玩家确认放量数字和停止条件。Tauri 安装包更新签名与 Windows Authenticode 是两套机制。

开发分支与本地候选包不改变线上更新源、发布标签或正式安装。
