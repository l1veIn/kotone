### 主会话替玩家定的（看得见的，不顺可以改）

- 叫法：新的窗口叫“**悬浮窗**”，两种状态“气泡”“小窗”；语音输入原来那个小条改叫“**输入条**”（一个词只指一样东西）。
- 外部 Agent 后台启动 Kotone 时不弹 UAC（UAC 会把玩家从全屏游戏里拽出来）。
- 三选一刷新后最好的那张变了要再说，不受 20 秒冷却限制（冷却只管不同推送别连着说）。
- 旧的“自动卡片”总开关关着的，只关“只有卡片”的推送，三选一不受影响。
- 外部 Agent 也能调语音输入卡片上的“重发”（只能重发那一条、只能一次；ADR 014 外部 Agent 能力全开）。

## 二、怎么验的

- 每个提交都单独编译过：在 `target/tmp/wt-verify`（单独的编译目录）里逐个检出，`cargo fmt --check`、`cargo clippy --workspace --all-targets -D warnings`、`pnpm -C apps/desktop check` 都过。
- 最后的代码：`cargo test --workspace` 1732 个通过、0 失败（34 个本来就忽略）；svelte-check 0 错误 0 警告（本体 + 英雄联盟 App）；Playwright 232 个全过（本体 189、插件 43），没有时过时不过的；`terminology.spec` 4/4；`release:verify`、`release:test` 8/8。
- 真机（隔离的 `KOTONE_HOME`、假客户端、不发任何输入）：`game_events_real.py` 14/14（选人卡出现、重随原地更新、选人结束）；`lol_tools_real.py --while-playing` 用真的 DeepSeek Key 39/41（`lol.scout` 里没有突破口，她自己从事实判断；没过的 2 项是“发出去”时她选了一键喊话而不是发到游戏聊天，两样在那个测试里都禁用，和这次无关）。测试前后玩家的 `~/.kotone` 一个字节没变。
- 玩家整轮都开着英雄联盟，所以编译都是低优先级、`-j 2`，没有对桌面发过任何输入。

## 三、还没验的

- **所有要管理员身份的**：UAC 流程、降权以后的子进程、管理员身份下的呼叫键和打字（我点不了 UAC）。
- **悬浮窗在真游戏里**：点、滚、拖时游戏的焦点；滚轮能不能到不可聚焦的窗口；多显示器；独占全屏。`floating_real.py`、`auto_card_real.py` 写好了没跑（会在桌面上弹窗口，玩家在用电脑）。
- **英雄联盟真对局**：真的三选一（识别速度、三格的位置、她说话的时机）、真的选人卡、隐藏身份的人在客户端选人接口里的样子、模型下载、OP.GG 海斗海克斯接口的真调用。
- **语音输入**：在悬浮窗和主窗口里点“重发”、事件触发自动化。
- 已知的小尾巴：选人卡的来源标签不带数据日期；`docs/design/lol-app.md` 的历史部分还写着消息提示和覆盖层（设计日志，没改）。

## 四、要玩家本人做的（一张清单）

### 要你点头的

- 你的 `~/.kotone/diagnostics/events.jsonl` 里有约 200 条测试写进去的 `inject_wait_modifiers`（context 为空、waitedMs=20 / timeoutMs=1000，2026-09-07 起）。要不要清掉？（清之前备份，只删这一种。）新的不会再写进去了。

### 默认管理员（要你点 UAC）

1. 第一次打开 rc.10：先出“以管理员身份运行 Kotone”的说明框，没有 UAC；点「好」→ UAC 点“是” → 重开；任务管理器“详细信息”里加“提升的”一列，kotone.exe 是“是”。关掉再开、开机自启：直接 UAC，不再说明。
2. 有一次 UAC 点“否”：照常打开；把英雄联盟客户端切到前面等几秒，再回 Kotone 窗口，看到“游戏在前面时有些功能用不了”，点「以管理员身份重开」能重开。
3. 管理员身份开着时：让她跑一句 `whoami /groups`，结果里是 Medium（不是 High）；让她打开一个网页、在聊天里点一个链接、打开识别历史的文件夹、从游戏列表启动英雄联盟：任务管理器里这些进程“提升的”都是“否”；打开的浏览器 / 文件夹窗口能到前面来。
4. 管理员身份开着、窗口收进托盘时，再双击桌面图标：不弹 UAC，窗口出来，任务管理器里只有一份 Kotone。
5. 英雄联盟客户端在前面、游戏在前面：呼叫键（Ctrl+\`）能接通；语音输入热键、停下热键、快捷指令、往游戏里打字都能用。
6. 管理员身份运行过以后，在「设置 → 系统」把开关关掉、以普通权限打开：设置、聊天记录、模型都还在、能改。

已知代价：管理员身份时从资源管理器往 Kotone 窗口拖文件会被 Windows 挡掉。

### 悬浮窗（在游戏里点、滚、拖）

7. 游戏里（无边框全屏）有卡片推过来时：小窗弹出，高度跟着卡片；点卡片上的按钮、点 ×、在上面滚滚轮、按住拖动——每一样做完，游戏都还在前台（键盘照样控制英雄），没有切出去。
8. 滚轮能不能往回翻：能的话告诉我，就把 ↑/↓ 按钮去掉。
9. 拖到别处以后，下一条推送从拖到的地方出来；游戏换到另一块屏幕时，悬浮窗跟着去那块屏幕。
10. 鼠标停在小窗上不消失，移开几秒后收起；她说话时气泡里照样显示她在说什么。
11. 独占全屏的游戏里不出现（推送照样进聊天）。

### 英雄联盟（海斗、排位各打几把）

12. 选人：聊天里和悬浮窗里出“选英雄”卡片；重随、换英雄时原地变，不多出一张；选人结束时卡片写“选英雄结束了”。
13. 海斗三选一：悬浮窗气泡里一行三格（首选 / 可选 / 可刷新），她说一句“中间那个”这类；刷新后最好的那张变了她再说，没变不说；卡片消失后那一行收起。第一次没有本地识别模型时，会推一张卡片问要不要下载（约 21 MB）。
14. 开局战绩：两队上下排、每人一行，点一行展开；有人隐藏身份时照样有那一行、标“隐藏了身份”；卡片下面没有风险提示，只有一个来源小标签。
15. 英雄页：来源小标签能点，换成 OP.GG / 腾讯 101 以后记住。OP.GG 默认开着。
16. 插件页「设置」：最下面“推送”一节列出开局战绩、这局总结、选英雄、海克斯三选一，每条一个开关；第一次打开英雄联盟插件页弹一次“风险和许可”，以后从“风险和许可”小链接打开。

### 语音输入

17. 在游戏里说一句发出去：聊天里出“你向「队伍」发了：……”，2 分钟内再说一句并进同一张。
18. 故意让一句发不出去（例如发的时候切到桌面）：出一张“没发出去”的卡片写原因，点“重发”回到游戏发出去；在悬浮窗里点和在 Kotone 主窗口里点都试一下。
19. 语音输入的历史里每条有“英雄联盟 · 队伍”这样的游戏和频道。

一键导入（符文 / 出装 / 召唤师技能）是 B 轮的，这一轮没有。
