## 核对过的现状（2026-11-26，`9701f74f`）

- 三选一的识别范围（`plugins/lol/src/pushes/augment_pick.rs` 的 `CARD_REGION = [0.12, 0.12, 0.76, 0.62]`）：不是全屏，是游戏窗口中间一大块（左右各留 12%，高度 12%–74%）。左下角聊天框的上半截落在里面，所以队友在聊天里打出海克斯的名字也会被当成三选一。

## 理解和决定

1. **呼叫键也有三种用法**（和语音输入的交互方式同样的说法）：现在的“按一下接通通话”、**录音笔**（按一下开始听、再按一下结束、交给她）、**一句话**（按一下说一句，说完自动结束、交给她）。在「设置 → 热键」的呼叫键那一行选。默认照旧（通话）。
2. **她说完就安静**：默认回答完不再接着听。只有她这次最后一句话以问号结尾（`？` / `?`）才自动再听一次（照现在的追问时长）。通话里玩家自己说“退下”等照旧。
3. **三选一改成推卡片**：和开局战绩一样推进聊天（悬浮窗里就是聊天小窗），卡片上写清三个海克斯各自的推荐程度（首选 / 可选 / 可刷新 / 没数据，照 AramHex 的规则），刷新时同一个 key 原地更新。“中间那个”这句语音照旧（同一条推送的更新不受冷却限制）。去掉单独的“一行三格”。识别范围收窄到三张卡片名字所在的那一横条，并且要三个名字左右排开才算出现了三选一，聊天框里的字不算。
4. **悬浮窗就是一个小的聊天界面**：
   - 右下角固定是她的头像（出现时一定有头像）。
   - 简单的一句话（她在听 / 在想 / 说了一句短话、推送的一行）：头像旁边是**气泡**。
   - 复杂的消息（卡片、工具调用、长回答、推送的卡片）：头像旁边是**聊天小窗**，内容就是聊天页那段对话实时的最近几条，直接用聊天页的组件（同一个时间线、同一套消息组件），不另写一套；能滚回去看。
   - 头像外面一圈**进度条**：走完了整个收起；鼠标停在上面就一直显示，移开再接着走。
   - 替代原来右下角的说话气泡（A 轮已经并进来了），A 轮写的“推送流”去掉。
   - 不抢焦点、能拖、记住位置、跟着游戏所在屏幕、独占全屏不显示：照 ADR 043 D6 不变。
