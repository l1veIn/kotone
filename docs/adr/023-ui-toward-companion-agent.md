# ADR 023：界面从“语音输入法”平滑转向“陪玩 Agent”

- 状态：Accepted（2026-11-18）
- 相关：[ADR 016](016-ui-foundation-shadcn.md)（设置窗口的组件与外观）、[ADR 022](022-sessions-memory-soul.md)（会话、记忆、SOUL）
- 2026-11-28：下文提到的“旧的单次陪玩”已由 [ADR 053](053-retire-old-companion-flow.md) 退掉（连同「琴音 → 权限」里“通话交给她”的开关）

## 问题

产品已经转向（琴音能看、能说、能动手、能替你对队友说话），但设置窗口还是按“语音输入法”排的：“通用”里一半是输入法（麦克风、录制热键、交互模式、悬浮窗），一半是琴音（声音与弹幕）和外观；琴音的东西散在“通用”“琴音陪玩 → 设置”“游戏适配”“高级”四处；“琴音陪玩 → 设置”里塞满了 AI 连接、陪玩热键、旧的单次陪玩、快捷指令、唤醒、气泡、游戏语音、权限。

## 决定（用户确认）

1. **语音输入仍是首页、排第一**（老用户的入口不变），首页顶部加一个显眼的入口引导用户用游戏陪玩；以后的版本再慢慢调整优先级。
2. **侧栏分两组**，按“琴音是谁、怎么交流、你玩什么”排：

```
语音输入
  语音输入      ← 首页（原“通用”里的输入、交互模式、悬浮窗），顶部有“试试游戏陪玩”
  文字处理
  历史记录
游戏陪玩
  琴音          聊天；设置（AI 连接、她能做什么）；以后加她是谁、她记得什么、她会什么（ADR 022）
  交流          你 → 她：陪玩热键、快捷指令、语音唤醒
                她 → 你：对话气泡、声音与弹幕
                她 → 队友：游戏语音（ADR 020）；队友 → 她：听队友（ADR 021）
  游戏          原“游戏适配”
  自动化
──────
设置            原“高级”，加“外观”（从“通用”搬来）
关于
```

3. **所有设置页内容宽度一致**（同一个内容列宽度，不再有“宽一些”的页面）。
4. **分步过渡**：
   - 第 1 步：只搬家、不改功能。设置项和它们的测试标识不变，页面标识尽量不变（“通用”页的内部标识仍是 `general`，只改显示名），老用户换个地方就能找到；
   - 第 2 步：随 ADR 022 补上“她是谁、她记得什么、她会什么”；
   - 第 3 步：首次引导换成陪玩 Agent 的流程（连上 AI → 选游戏 → 认识琴音 → 可选开唤醒和游戏语音），语音输入法放在“也可以当输入法用”。
5. 每个设置项都能交给琴音改（人能做的她都能做），页面主要用来看和兜底。

## 实施记录（2026-11-18，分支 `claude/kotone-agent`）

- 第 1 步：已做（侧栏两组、「交流」页、“高级”改“设置”并加外观、内容宽度一致、首页的游戏陪玩入口）。
- 第 2 步：「琴音」页分“聊天 · 她是谁 · 记忆 · 技能 · 设置”。
- 第 3 步：**做的是轻量版**——用户决定语音输入仍排第一，所以没有把引导整个换成陪玩流程，而是在设好语音输入后加一页介绍游戏陪玩，可以“去认识她”（进「琴音」页）或“先只用语音输入”。
- 测试：`e2e/navigation.spec.ts`、`e2e/companion-profile.spec.ts`、`e2e/onboarding.spec.ts`；全部 Playwright 96 个通过。

### 修订（2026-11-18，玩家试用后的反馈）

- 「交流」页取消：它和「琴音 → 设置」、左下角「设置」都是“各种设置”。怎么叫琴音、她怎么回答、游戏语音并进「琴音 → 设置」（顶部有分组跳转）；左下角「设置」只放整个 Kotone 的（模型、API 连接、热键、外观、系统）。
- “陪玩热键”改成“呼叫琴音”：按键版的语音唤醒，按一下就在气泡里听、说完自动提交，不再有输入方式可选；默认 `~` 键。首页和聊天输入框都有“呼叫琴音”按钮。
- 「游戏」改名「游戏列表」：上面是本机装的游戏（带图标），下面是游戏配置。
- 「自动化」不再分页：一个列表（▶ / ■、定时、详情），最下面可以展开全部记录。
- 头像以右下角气泡为准，聊天和「她是谁」统一用同一个组件。
- 测试：Playwright 全部更新（见 CHANGELOG）；真机检查了游戏列表（10 个游戏都有图标）、定时自动化（每分钟的定时自己跑了一次）、上传头像能显示。
