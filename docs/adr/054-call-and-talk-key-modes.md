# ADR 054：说话键和呼叫键一套方式；一个命令可以有几个键，每个键带自己的方式和“什么时候管用”

状态：Accepted（2026-11-28）/ 已实现（单元测试、浏览器预览的端到端测试），待真机（按住的手感、侧键只在游戏里时游戏外照常放行）。

修订：[ADR 033](033-call-mode.md) 2026-11-26 修订（呼叫以后的三种方式 → 五种，通话这一种改叫“一直听”）、[ADR 040](040-hotkeys-belong-to-core.md) D8（“不存按一下 / 按住”）和“一个命令一个键”、[ADR 051](051-lol-happy-path.md) 清单里“呼叫键”那一行。

## 背景

玩家（2026-11-28）：

> “现在的模式不齐，而且默认按键不够友好，考虑到第一批用户是LOL用户……配置上可以追求灵活多变，复杂度虽然会增高但是我们本来就支持Agent自己改配置，所以复杂度增加没什么成本”

当时的样子：

- **说话键**（语音输入，`voice-input.talk`，默认 `CapsLock`）有对讲机（按住）、录音笔、说一句就走、独奏四种（`interactionMode`）。
- **呼叫键**（`kotone.call`，默认 `Ctrl + ~`）有说一句就走、录音笔、通话三种（`assistant.callMode`），**只认按下**：宿主把具名热键的按住 / 松开丢掉（“具名的按住热键现在没有”），所以她没有按住说话。
- 热键表 `hotkeys.bindings` 一个命令只认第一条，方式是全局的。英雄联盟玩家最顺手的是鼠标侧键按住说，可侧键在桌面上还有“后退”的用处。

默认键的事玩家说“可以自己绑”：不换默认键，让绑键这一步更顺手。

## 决定

### 1. 两个键一套方式（五种）

| 给玩家看 | 怎么用 | 她（`assistant.callMode`） | 说话（`interactionMode`） |
| --- | --- | --- | --- |
| **自动** | 点一下 = 说一句就走；按住超过一会儿（缺省 300 毫秒，`hotkeys.holdMs`）= 按住说话，松开就是说完了 | `auto`（新） | 只能存在键上（`mode: "auto"`，见第 2 条） |
| **按住说话** | 按住说，松开交出去 | `hold`（新） | `push-to-talk` |
| **说一句就走** | 按一下，说完自动停 | `one-shot` | `one-shot` |
| **录音笔** | 按一下开始，再按一下结束（语音输入先预览） | `dictation` | `dictation` |
| **一直听** | 她：接通通话，说“退下”、再按或一阵子没人说话挂断；语音输入：说一句发一句，再按停 | `call` | `solo` |

- 存的值都不改名（旧值照读）；只统一给玩家看的名字（`docs/glossary.md`）。`对讲机`、`独奏模式` 不再出现在界面上，“通话”仍是那件事本身（接通 / 挂断）。
- **新装**：她的默认是**自动**；说话的默认还是按住说话。**老配置**：文件里没有 `callMode` 的读成说一句就走（读取时写明 `one-shot`，`settings::migrate_call_mode_json`），玩家选过的一律不动。不认识的值照旧读成说一句就走。
- 旧版本读到 `auto` / `hold` 当说一句就走（`#[serde(other)]`），配置不会坏。`interactionMode` 没有这个保护（旧版本读到不认识的值会把整份配置当坏的），所以说话的“自动”只存在热键表的那一条上。
- **自动**怎么实现：按下时照说一句就走开始听，**按着的时候静音判停不算数**（`Orchestrator::key_held`，收音循环看它）；松开时按了多久 ≥ `holdMs` 就当场结束（语音输入照对讲机的松手宽限），短于它就什么都不做，接着照说一句就走等你说完。纯逻辑在 `hotkey_options::auto_release_ends`。
- **她的按住说话**：宿主现在接具名热键的按住 / 松开（`HookEvent::NamedHold`）：按下开始听（不判停，`SessionOrigin::CallHold`），松开交给她，Esc 照旧取消。一直听里按下 = 挂断，这一下的松开不再算。

### 2. 热键表的一条可以带 `mode` 和 `when`；同一个命令可以有几条

```jsonc
{"key": "Mouse5", "command": "kotone.call", "mode": "hold", "when": "game"}
{"key": "Ctrl+Backquote", "command": "kotone.call"}
```

- `mode`（只对 `kotone.call`、`voice-input.talk` 有用）：`auto` / `hold` / `one-shot` / `dictation` / `continuous`（也认 `push-to-talk`、`solo`、`call`）。不写 = 用那个命令的全局方式。写了别的值，保存时说人话拒掉。
- `when`：`always`（缺省，不写就是它）/ `game`（**认得的游戏窗口在最前面时**）/ `game:<游戏配置 id>`（只在这个游戏里；只写 id 也认）。不在游戏里时这个键**原样给前台程序**（不吞），侧键在桌面上照样是“后退”。
- 同一个命令几条都登记（以前只认第一条）。表里每条一行，第二条起行 id 是 `<命令>~<n>`，登记 id 是 `<第 1 期的 id>~<n>`（`assistant~2`、`record~2`）。
- **第一条的方式就是那一页上选的**：她的「唤醒」页改的是 `assistant.callMode`，语音输入页改的是 `interactionMode`；从那两页改的时候，第一条上写着的 `mode` 去掉（`Settings::reconcile_hotkeys`），免得“那边改了这边不动”。「设置 → 热键」上改第一条的方式：能写进全局字段就写全局字段（她的五种、说话除了“自动”），只有说话的“自动”写在那一条上。第二条起都写在那一条上。
- **冲突**：同一个键两条只有“什么时候管用”重叠才算冲突（`always` 和谁都重叠；`game` 和 `game`、和某个游戏重叠；两个不同的游戏不重叠）。游戏配置里的聊天键只在那个游戏里重叠（`game:dnf` 的键不和英雄联盟的 Enter 冲突）。Esc 不管 `when`，照旧不让用。
- **钩子里怎么判**：`hotkey_options` 里一个原子量记着最前面是哪个游戏（游戏配置 id 的哈希，0 = 不是游戏），桌面端每 250 毫秒看一次前台窗口（窗口没换不查进程名）；钩子回调只读这个原子量，不做 IO、不拿别的锁。带 `when` 的键只有低层钩子能做（系统热键注册没法放行），和鼠标侧键一样强制用钩子。
- 她用现成的 `settings.update` 改 `hotkeys.bindings`（设置说明里写了例子：“把呼叫键改成侧键、按住说话” = 加一条 `{key: "Mouse5", command: "kotone.call", mode: "hold", when: "game"}`），`hotkeys.status` / `hotkeys.conflicts` 照旧看结果。

### 3. 设置页

「设置 → 热键」里两个说话的命令（呼叫键、说话）每一条旁边一个“方式”下拉和一个“什么时候”下拉（一直 / 在游戏里 / 每个游戏配置），下面一个“再加一个键”；第二条起有“删掉”。别的命令不显示这两样（要改让她改）。她的「唤醒」页“按下以后”多出自动、按住说话两格，通话改叫一直听；语音输入页的交互方式名字跟着换，多一格“自动”（写在第一条键上）。

### 4. “准备好了吗”里的呼叫键

那一行改成“按一下你想用的键”：点“录入”直接按（和「设置 → 热键」同一个录键），提示英雄联盟玩家用鼠标侧键（录到侧键时自动设成只在游戏里）；旁边“就用 Ctrl + ~”。没绑之前默认键照旧能用。

**什么时候算 ✓**：呼叫键不是空的，并且下面任一条成立：玩家自己录过键（键不是默认的，或者有第二个呼叫键），或者点过“就用 Ctrl + ~”（`ui.callKeyChosen`，新字段，旧配置没有 = 没点过）。老用户的呼叫键还是默认的时候也会看到这一行一次，点一下就过。

### 5. 不在这一次

读英雄联盟自己的按键文件查冲突（侧键、`CapsLock` 在游戏里有没有用）——以后一步。

## 实现情况

- core：`hotkey_options.rs`（五种方式、`when`、前台游戏的原子量、自动的松手判断）；`hotkey.rs` 的匹配器每个具名键和主键带一个门（`KeyGate`），门关着就像这个键没登记；`hotkey_table.rs` 每条一行、冲突看 `when`、登记计划带门和按住；`orchestrator` 加她的自动 / 按住说话和语音输入的按指定方式开始（`SessionOrigin::HotkeyPreset`）。
- 桌面端：`hotkey.rs` 接 `NamedHold`、第二条起的登记 id、门；`hotkey_gate.rs` 看前台游戏；`hotkey_table_cmd.rs` 加改方式 / 改“什么时候” / 加一条 / 删一条的命令。
- 待真机：按住 300 毫秒的手感、侧键只在游戏里时切出游戏照常放行、RegisterHotKey 回退时带 `when` 的键报“要用低层钩子”。
