# 试玩：呼叫就是通话（ADR 033）

自动测试（`scripts/manual-e2e/call_mode_real.py`）用虚拟麦克风验证了通话的流程；**开着音箱时她的声音能不能从麦克风里消掉，只有真麦克风 + 真音箱能验**。下面几步请在不打游戏时试一次，有不对的地方记下时间（日志 `~/.kotone/kotone.log` 里有对应的行）。

准备：「设置 → 怎么叫她」里“通话”是 30 秒、“开着音箱也能打断她”开着；用音箱（不戴耳机），音量调到平时打游戏的大小。

| # | 怎么做 | 应该 | 日志里找 |
| --- | --- | --- | --- |
| A1 | 按呼叫键，说“你好” | 她回答；之后不按键直接说“那你能做什么”，她接着回答 | `call: connected`、`call: player started speaking` |
| A2 | 让她说一段长一点的（“详细说说打野怎么刷野”），她说话时**什么都不说** | 她一口气说完，**不会自己停下**（音箱里她的声音没被当成你在说话） | 不应出现 `voice reply: ducked`；结束时有 `echo cancel: stopped … stats` |
| A3 | 同上，她说到一半时你说“等一下，现在几点了” | 她的声音马上变小，你说完一两秒内停下，回答几点了 | `voice reply: ducked`、`玩家开口打断了她` |
| A4 | 同上，她说话时你只“嗯”一声或咳嗽一下 | 她的声音变小一下又恢复，接着说完 | `back to full volume` |
| A5 | 开着游戏声音（或放首歌），按呼叫键说一句话，然后不说话 | 她回答完以后不会因为游戏声 / 歌声又开始“听到”什么 | 不应反复出现 `call: player started speaking` |
| A6 | 说“退下”（或“安静”“挂了”） | 马上安静、挂断；之后说话她不再听 | `call: ended (玩家说了退下)` |
| A7 | 接通后 30 秒不说话 | 气泡倒计时结束、挂断 | `call: ended (没人说话)` |
| A8 | 接通后再按一次呼叫键 | 挂断（话说到一半会把这句收完交给她） | `call: ended (呼叫键)` |
| A9 | 让她做一件要确认的事（例如把某个工具设成“询问”），她问“可以吗？”时不回答，等她说“没听清” | 之后说“允许”，事情接着做，不用点窗口 | `玩家用嘴回答了还在等的确认（允许）` |
| A10 | 打一局，平时怎么叫她就怎么叫 | 游戏声音、队友语音（从音箱出来的）不会让她乱打断、乱回答 | |

如果 A2 她会自己停下、或者 A5 她老是“听到”东西：先把“开着音箱也能打断她”关掉（她说话时不听，按呼叫键打断），把那段时间的日志发给我。

已知限制：

- 只能消掉**默认扬声器**放出来的声音；游戏声走的是另一个输出设备时消不掉。
- 通话里你说的每句话都算对她说的；和队友语音说话前先说“退下”（D3，等你决定要不要让她自己判断）。
- 戴耳机不受影响。
