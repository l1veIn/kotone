## 一、设计语言

### 1. 风格：“记分纸”

**一句话**：像赛场边的一张记分纸——白纸（夜里是深色的纸），墨色的字和细线，数字对齐成列；**颜色只用来表达意思**（我方 / 对面、胜负、稀有度、开黑），不拿来装饰。

为什么这样定：

1. **信息密度学 LeagueAkari**：一屏放 10 个人、每人十几样东西，装饰越少越好读。细线分隔、等宽数字、小圆角方块，是表格类界面最耐看的做法。
2. **原创，不像拳头**：拳头的英雄联盟界面是金色描边、斜切角、六边形、海克斯科技的青蓝发光、衬线标题字。这里一样都不用：没有描边装饰、没有发光、没有渐变底、没有六边形，标题用无衬线的系统字。英雄联盟的味道只来自游戏素材本身（英雄头像、装备、海克斯图标）。
3. **两个宿主里都好看**：纸和墨（底色、字色、线色）用宿主给的颜色，放在 Kotone 里就是 Kotone 的深蓝底，放在 Claude 里就是 Claude 的暖白 / 暖黑底；App 自己只带“表达意思的颜色”和形状、字号、密度。不和宿主打架，也不会因为宿主换了配色就丑掉。

这套风格的几个记号（认得出是它）：

- 每行左边 3 px 的**队伍边条**（我方蓝、对面橙），整块连成一条；
- 表头的**队伍记号**：我方 ■（方块），对面 ◆（菱形）；
- **突破口用墨线圈出来**（不是红色，是“拿笔圈一下”），配一块墨底反白的“突破口”小牌；
- 开黑是**字母小牌**（A、B、C、D，各一个颜色）；
- 页面顶上的分页是**墨线下划线**，主按钮是**墨底**（亮色里黑底白字，暗色里白底黑字）。

### 2. 和宿主怎么配合

**主题（亮 / 暗）**：

- 页面连上宿主后调 ext-apps 的 `applyDocumentTheme(hostContext.theme)`：它在 `<html>` 上写 `data-theme` 和 `color-scheme`。收到 `ui/notifications/host-context-changed` 里的 `theme` 时再调一次。
- `tokens.css` 里的颜色全用 `light-dark()`，跟着 `color-scheme` 走；宿主没给主题时 `color-scheme: light dark`，跟着系统（`prefers-color-scheme`）。两种情况都管到了，只写一份颜色。
- 要求 `light-dark()`：Chromium 123+、Safari 17.5+（WebView2、Claude Desktop、claude.ai 都满足）。

**宿主的样式变量**（规范的 “Theming”）：

- 页面调 `applyHostStyleVariables(hostContext.styles.variables)`，**写在 `document.documentElement` 上**（默认就是）。`--lol-*` 定义在 `:root`，引用宿主变量，写在别的元素上不生效。
- 只跟宿主这几样：`--color-background-primary / secondary / tertiary`、`--color-text-primary / secondary / tertiary`、`--color-border-primary / secondary`、`--color-ring-primary`、`--color-text-danger`、`--font-sans`。没给的用 `tokens.css` 里的值。
- 宿主给了 `styles.css.fonts` 就 `applyHostFonts`。中文字体永远接在宿主字体后面（见第 4 小节）。
- 字号、间距、圆角、表达意思的颜色**不跟宿主**（规范里有 `--font-text-*`、`--border-radius-*`，不用）：这是 App 自己的风格，也是信息密度的保证。

**显示方式**：

- `<html data-display="inline | fullscreen | pip">`，值来自 `hostContext.displayMode`，变了跟着改。
- `inline`（聊天卡片）：页面底色透明，不画外框（宿主画外框和“英雄联盟发来一张卡片”那一行），用紧凑的组件（第三节每页的“卡片”）。
- `fullscreen`（插件页、Claude 的全屏）：画完整页面，有顶栏和页脚。
- 宽窄用**容器查询**（`.app { container-type: inline-size }`），在 iframe 里和样张里都一样。断点：`< 520` 窄（卡片 360–480）、`520–879` 中、`≥ 880` 宽（两队并排）。
- 卡片右上角的“打开”按钮：宿主的 `availableDisplayModes` 里有 `fullscreen` 才显示，点了发 `ui/request-display-mode`。Kotone 里点卡片本身就打开插件页（宿主做），按钮照样能用。

**Kotone 这个宿主该传什么**（给做 MCP Apps 显示的人；Kotone 的配色在 `apps/desktop/src/lib/appearance/palettes.css`）：

| 标准变量 | 插件页（fullscreen） | 聊天卡片（inline） |
| --- | --- | --- |
| `--color-background-primary` | `--background` | `--card` |
| `--color-background-secondary` | `--card` | `--muted` |
| `--color-background-tertiary` | `--muted` | `--secondary` |
| `--color-text-primary` | `--foreground` | 同左 |
| `--color-text-secondary` | `--muted-foreground` | 同左 |
| `--color-text-tertiary` | `--muted-foreground` 和 `--background` 七三开混出来的颜色 | 同左 |
| `--color-border-primary` | `--hairline` | 同左 |
| `--color-border-secondary` | `--border` | 同左 |
| `--color-ring-primary` | `--ring` | 同左 |
| `--color-text-danger` | `--destructive` | 同左 |
| `--font-sans` | 外观设置里的界面字体 | 同左 |

传算好的颜色值（`getComputedStyle` 读出来的），换配色、换亮暗时用 `host-context-changed` 再发一次；`theme` 照 `data-theme` 给。

| `--lol-party-a…d` | 紫 `#6d4fd8`、青 `#0b7f80`、粉 `#b8336f`、橄榄 `#776808` | `#a897ff`、`#38c9c9`、`#f07ab0`、`#cdbd45` | 开黑字母小牌的底 |

规则：

- 字的对比度：正文 ≥ 4.5（亮暗都核过，`--lol-text-3` 在白底上 4.5、暗底上 5.1）；只当记号用的颜色（边条、表头记号）≥ 3。
- **颜色从不单独表达意思**：胜负配“胜 / 负”字或“实 / 淡”；队伍配位置、表头字和 ■ / ◆；开黑配字母；稀有度配边框粗细和名字；突破口是墨线 + 字。
- 不用纯红纯绿的大色块；淡底（`-soft`）只在小标签和“我”那一行。

### 4. 字

- **字体**：`var(--font-sans, "Segoe UI Variable Text", "Segoe UI", system-ui), "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Source Han Sans SC", sans-serif`。宿主给的字体只管西文，中文接 Windows 自带的微软雅黑；不打包字体。
- **数字**：不换字体，统一 `font-variant-numeric: tabular-nums`（Segoe UI、微软雅黑都有等宽数字），让 KDA、胜率、伤害对齐成列。千分位按语言（`12,345`）。百分比：这局、战绩里取整（`60%`），英雄页、强度榜一位小数（`51.2%`）。
- **字号阶梯**（px，字号 / 行高）：

| 名字 | 大小 | 用在哪 |
| --- | --- | --- |
| `2xs` | 10 / 12 | **只给纯数字**：头像上的等级、开黑字母 |
| `xs` | 11 / 16 | 表头、标签、出处、时间、段位字 |
| `sm` | 12 / 18 | 行里的数字、玩家名（默认正文） |
| `md` | 13 / 20 | 行里的主字：英雄名、分页名、卡片标题 |
| `lg` | 15 / 22 | 页头的名字、区块大标题 |
| `xl` | 18 / 24 | 页头的大数字（战绩页的胜率） |
| `2xl` | 24 / 30 | 结算的“胜利 / 失败” |

- 中文最小 11 px（微软雅黑 10 px 发糊）。粗细只有 400 / 500 / 600；只有“胜利 / 失败”用 700。

### 5. 间距、圆角、阴影、动效

- 间距：2、4、6、8、12、16、24、32（`--lol-sp-1…8`）。行内元素之间 6，行的上下内边距 8，区块之间 12，页面边距 16。
- 圆角：**小圆角的方形是这套风格的形状**。≤ 24 px 的图标和标签 3 px；32 px 的英雄头像 4 px；40–56 px 的头像、按钮、输入框 6 px；区块 8 px。圆形只给召唤师头像和琴音的头像。
- 阴影：内容是平的，没有阴影；只有浮出来的东西（悬停提示、菜单、消息提示）有 `--lol-shadow-pop`。
- 动效：只有淡入和 2–4 px 的位移，120–180 ms；没有呼吸、闪烁、骨架屏的流光。`prefers-reduced-motion` 时全部关掉。

### 8. 我方和对面怎么区分

不能只靠颜色（色弱的人分不清红蓝、红绿）。一共五层，任何一层单独都能分：

1. **位置**：宽的时候我方在左、对面在右；窄的时候对面在上（卡片的目的是“看对面”）、我方在下。
2. **表头的字**：“我方”“对面”。
3. **表头的记号**：我方 ■ 方块，对面 ◆ 菱形。
4. **行左边的边条**：我方蓝、对面橙。蓝橙是红绿色弱也分得开的一对（两者亮度接近，所以前三层不能省）。
5. **“我”**：我那一行淡蓝底 + 蓝框“我”小牌。

不在我方 / 对面语境里的地方（看别人的单局详情、战绩列表），不用这两个颜色：单局详情里两队叫“胜方 / 负方”，边条是灰的。

## 二、数据：页面要的字段

### 0. 约定

- 页面数据就是工具结果的 `structuredContent`（原则 10：给琴音的文字一个字不改，`lol_tools_real.py` 照过）。下面“现有”是 `plugins/lol/src/pages.rs`、`stats_tools.rs` 现在就有的；“**新**”是调研 G0.1 要补的（数据都已经拿到，只是没放进页面数据）。字段名是建议，实现时改了名字就同时改这份文档。
- **实现时的名字（2026-11-25）**：素材层先补的字段照它的名字用，没改名（[插件重构计划](../plugin-refactor.md)第九节“素材层和页面数据”）：符文是 `perks: {keystone, primaryStyle, subStyle}`；段位是 `ranked.solo / flex: {queue, tier, division, lp, wins, losses, highestTier, label, crest}`；装备只列有东西的格子，每件带 `slot`（0–6，6 是饰品），页面按 `slot` 排成 6 + 1 格；海克斯的 `rarity` 是客户端的写法 `kSilver / kGold / kPrismatic`（页面两种写法都认）；召唤师头像多一个 `profileIcon`（路径）；战绩每局的英雄等级叫 `level`。“这局”的 `phase`、`phaseSince`、`namesHidden`、`bench`、`result`、`resultPending`、每人的 `pick` 和带种类的 `tags` 照本文的名字加在 `pages.rs`（`match_page_in` + `MatchStage`）；阶段由后台写，没写时 `phase` 是 null，页面显示“在对局里”。
- 新的共用类型：

```ts
/** 装备、召唤师技能、符文、英雄技能：Named 加一个图标路径（客户端资源路径，拿不到时空字符串）。 */
interface Icon { id: number; name: string; icon: string }
/** 海克斯：再加稀有度（和现在 MayhemAugment.rarity 的写法一样，小写）。 */
interface Augment extends Icon { rarity: "silver" | "gold" | "prismatic" | "event" }
/** 段位：/lol-ranked/v1/ranked-stats/{puuid} 的 queueMap.RANKED_SOLO_5x5 / RANKED_FLEX_SR。 */
interface Rank { tier: string /* "DIAMOND"；没定级 "" */; division: string /* "II"；大师以上 "" */; lp: number; wins: number; losses: number; highest: string /* highestTier，没有 "" */ }
interface Perks { keystone: Icon | null; primary: Icon | null; sub: Icon | null }
/** 标签带种类，页面按种类上色；text 还是现在 scout::tags 的那句话。 */
interface Tag { kind: "win_streak" | "loss_streak" | "first_time" | "main"; text: string }
```

- 英雄、召唤师头像、段位徽章按 id 推路径（第一节 7），不加字段。
- 旧的 `rank`（“黄金 2”这样的字符串）留着，给旧卡片和没有 `ranked` 时用。

### 1. 时机表

| 阶段 | “这局”页 | 自动卡片 | 消息提示 | 覆盖层（保持现在的做法） | 给琴音的一句 |
| --- | --- | --- | --- | --- | --- |
| 客户端打开 | 阶段牌变成“在房间”等 | 无 | 无 | 无 | 无 |
| 大厅、排队、确认 | 阶段牌；页面写“进了选人，这里会显示这局的人” | 无 | 无 | 无（自动接受照旧） | 无 |
| **选人** | 选人状态（第三节 1）；查得到名字的队友马上开始查 | **不发** | **不弹** | 选英雄覆盖层 | 无 |
| **加载** | 10 个人 | **开局战绩**：10 人都查完就发；进加载 20 秒还没查完也发，写“还在查 N 人” | “对面的战绩到了” | 无 | 有（下面第 2 小节） |
| 对局中 | 不变，阶段牌“对局中” | 不发 | 不弹 | 海斗三选一评分 | 无 |
| **结算** | “刚结束”头 | **这局总结**：拿到结果就发；60 秒拿不到不发 | “这局的总结好了” | 收起 | 有 |
| 客户端关闭 | 阶段牌“客户端没开”；页面留着上一局 | 无 | 无 | 收起 | 无 |

**不发的情况**：训练模式、自定义对局、观战；重连、刷新（一局一种卡片只发一次）；重开局（提前投降、有人没进）不发“这局总结”；插件设置里“自动卡片”关了两种都不发。

### 2. 自动卡片

- 卡片就是页面的 inline 版本（`ui://kotone/lol/match` 的快照、`ui://kotone/lol/game` 带 `justEnded`），和琴音调工具时出的卡片同一个组件。
- 宿主在卡片上面画一行“[logo] 英雄联盟发来一张卡片 · 时间”（ADR 039 D3：写明是哪个插件发来的）。
- 给琴音的那句，追加在对话末尾，按不可信数据处理，不超过约 120 字（调研第五节的例子）：
  - “英雄联盟发来一张卡片：开局战绩（海斗）。对面可能的突破口：寒冰，近 20 局 6 胜 14 负、场均死 13 次。我方有 3 人开黑。”
  - “英雄联盟发来一张卡片：这局赢了（海斗，18 分 32 秒）。你用伊泽瑞尔 12/3/20，伤害全队第一。”
- 通话中：卡片马上出现，这句话等这一轮结束再追加（ADR 039 D3）。

### 3. 消息提示（右下角的小窗）

照桌面聊天软件（QQ、微信电脑版）的新消息提示：头像 + 一句话，点开跳到那条消息，几秒后自己消失。样张第三张图。

```
╭──────────────────────────────────────────────╮
│ ╭──╮                                      ×  │   320 × 72（逻辑像素）
│ │琴│ {name} · 英雄联盟                        │   头像 40 圆形，右下角压插件 logo 18（2 px 卡片色描边）
│ ╰─▣╯ 对面的战绩到了                            │   第一行 12 px 次要字色；第二行 14 px 500，一行，放不下省略
│▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔                     │   底部 2 px 倒计时线（主色），从满到空
╰──────────────────────────────────────────────╯
```

- **大小和位置**：320 × 72 逻辑像素，按那块屏幕的 DPI 换算。放在**前台窗口所在显示器的工作区右下角**（避开任务栏），边距 24（和气泡一样，ADR 018）。右下角排成一列（2026-11-25，ADR 039 实施记录“右下角排成一列”）：语音输入悬浮窗在右下角、气泡也在右下角而且正显示着时，消息提示放在它们上面，隔 12；它们后出来、叠上了消息提示时，消息提示往上让。
- **外观**：用 Kotone 自己的配色（它是本体的窗口，不是英雄联盟 App）：卡片底 `--card`、字 `--foreground` / `--muted-foreground`、1 px `--hairline` 边、12 px 圆角、阴影 `0 10px 28px`（亮 16% 黑、暗 55% 黑）；倒计时线用 `--primary`。亮暗跟着 Kotone 的外观设置。
- **内容**：琴音的头像（当前角色的头像，没有就用名字第一个字的渐变圆）；插件 logo 小角标；“{name} · {插件名}”；插件给的一句话（≤ 16 个字，插件不给时用“{插件名}发来一张卡片”）。右上角 × 只在鼠标移上去时出现。
- **出现和消失**：从下往上 8 px + 淡入，180 ms；停 **6 秒**；鼠标在上面时不计时，移开后再等 2 秒；淡出 + 往下 4 px，160 ms。`prefers-reduced-motion` 时只淡入淡出。没有声音。
- **点它**：打开 Kotone，切到聊天页、那段对话，滚到那张卡片，卡片外圈闪一次主色（1.2 秒）。点 × 只关掉。
- **不抢焦点**：不可聚焦、不进任务栏、置顶、`SW_SHOWNA` 显示（不激活窗口），照 ADR 018 气泡窗和 ADR 032 的精神；和气泡不同，它能点（不整窗鼠标穿透）。键盘和读屏不管它（真正的内容是聊天里的卡片）。
- **不弹的情况**：游戏独占全屏；“{name} → 交互”里的开关关了（卡片照发）；Kotone 窗口在前台而且正显示着那段对话（卡片就在眼前）。
- **同时只有一个**：新的来了替换旧的（淡出淡入），不叠。一局最多两次。

### 4. 覆盖层

保持现在的做法（本体的覆盖层，ADR 038 D5）：选人时选英雄覆盖层，海斗三选一时每张卡片上的评分。今晚如果做 G8、G24（调研“今晚做”第 9 条），视觉照这套语言：

- 底照旧是半透明深色（盖在游戏上），字用暗色主题的值；
- 评级字母小牌：S 胜色、A 我方蓝、B 正文色、C 提醒黄、D 负色，字母本身就能分；
- 三选一的判断：“首选”胜色、“可选”正文色、“可考虑刷新”负色，配字；最好的那张从金色描边改成 2 px 白色墨线（不用金色，也和 App 里“突破口用墨线圈”一致）；
- 出处小字照旧（aramhex-data 要署名）。

2026-11-25 做了（[插件重构计划](../plugin-refactor.md)第九节“覆盖层对齐 AramHex”，颜色在 `plugins/lol/ui/overlay.css`）：

- **三选一标签**三行：评级小牌 + 判断（大字）；“+7.9 · 57.8% · 1.1万局”；依据“棱彩第 2/38 · 样本少”+ 出处。高是游戏画面高度的 8.5%，底边在卡片名字上面 1%。不到 300 局的变淡（70%）。
- **选英雄面板**：每行 评级小牌 · 英雄 ·（你）· 胜率 · 第几 / 共几，“你”那一行我方淡底；备选两个一行，比你高的胜色 + ↑（颜色不单独表达意思），最高的 2 px 白色墨线圈；高度按行数给（标题、出处和上下边 7.5%，每行 2.9%），字号按面板宽度（5.2cqw）。没有一项数据时不显示。
- 海克斯的评级是同稀有度里的名次换算的（AramHex 用的是腾讯的官方层级，我们没有这份数据）。

## 五、插件 logo

### 1. 网格和风格

- 48 × 48 视框；整块是 12 px 圆角的方块（插件页卡片上显示 40 px，正好是现在的图标格大小）；里面一层 1 px 的白色细线（14% 不透明），让 logo 在和它颜色接近的底上也有边。
- 图形是白色，画在中间 24 × 24 的区域里（可以出到 28 × 28），线宽 2.2–3，圆头圆角；第二层意思用 55% 白或底色“镂空”。**平的**，不用渐变和阴影。
- 每个一个主色，中等亮度：白色图形和底色的对比度 ≥ 3.5；方块和 Kotone 暗底（`#1a1a2e`）、Claude 暗底（`#262624`）的对比度 ≥ 2.7，白底上 ≥ 3.5（样张里四种底都看过）。
- 文件：`plugins/<id>/logo.svg`，带 `<title>` 和 `aria-label`。

| 插件 | 文件 | 主色 | 图形 | 意思 |
| --- | --- | --- | --- | --- |
| 英雄联盟 | `plugins/lol/logo.svg` | 靛蓝 `#4c58dd` | 一张三条路的小地图：方框是上路和下路，对角线是中路，淡的一道是河；左下实心的角是我方基地，右上空心的角是对面基地 | 这局、地图、我方实 / 对面空（和 App 里的记号一致）。分路图标是同一张地图 |
| 游戏语音 | `plugins/game-voice/logo.svg` | 绿 `#179160` | 带麦克风的耳机 | 琴音在游戏语音里替你说话，你也照样听得见队友 |
| 网易云音乐 | `plugins/music/logo.svg` | 紫 `#9b47c8` | 一朵云里一个音符 | “云” + “音乐”。**不用网易云的红色和唱片标志** |
| 同传 | `plugins/interpreter/logo.svg` | 青蓝 `#0b87aa` | 后面一个空心气泡（外语），前面一个实心气泡（翻好的话） | 一句话变成另一种语言 |
| 语音输入 | `plugins/voice-input/logo.svg` | 橙 `#d46a17` | 麦克风，下面一行正在打出来的字（三个点）和光标 | 说的话变成聊天框里的字 |

都是原创：没有用拳头 / 英雄联盟的标志、字体、金色和六边形，没有用网易云的红色和唱片。

### 2. 用在哪

- **插件页的卡片**：40 px，直接用 logo（它自己就是一块有底色的方块），替掉现在 `PluginsPage.svelte` 里 Lucide 图标加 `bg-primary/12` 的那一格。关着的插件：`filter: grayscale(1); opacity: .55`。
- **App 顶上的“← 插件 · 名字”**：20 px，放在名字前面。
- **自动卡片上宿主画的那一行**：16 px。
- **消息提示**：18 px，压在琴音头像的右下角。
- 内置插件在前端用 Vite 引进来（`?url` 或直接 import），挂在 `PLUGIN_UI` 上；`kotone.exe mcp` 对外的服务器说明里可以带英雄联盟的 logo（MCP 的 `icons`，data URI），由做第 12 条的人定。

### 3. 第三方插件没有 logo 时

- 第三方 MCP 服务器有自己声明的图标（MCP 的 `icons`、`.mcpb` 的 `icon`）就用它（ADR 039 D8）。
- 没有：同样 48 网格、12 px 圆角的方块，底色按插件 id 算一个哈希，从 8 个颜色里挑（上面 5 个主色加 石板 `#5b6b7f`、玫红 `#b0466f`、橄榄 `#6f7a1f`），中间是**名字的第一个字**（中文取第一个字，英文取第一个字母大写），白色，字号是方块的 46%，600 粗。样张里有两个例子（“天”“M”）。

## 七、还没定的、实现时注意的

1. 国服客户端的**图片接口**没实测（调研第六节 1）；拿不到时一律走 CommunityDragon，占位规则保证页面能用。
2. `assetBase` 怎么交给页面、Kotone 的回环代理怎么放进 CSP：做素材层（G0）的人定，写回第一节 7。
3. 别的宿主里设置页能不能改开关：看有没有只给页面用的设置工具（第三节 6）。
4. 样张是假数据。真数据里名字很长、段位没有、10 个人都还在查、全是隐藏战绩这些情况，实现时用假客户端各截一张图对照。
5. `light-dark()` 太旧的引擎不认（Chromium 123 以前）：今晚的宿主都满足，不做兜底。
6. 卡片的高度：开局战绩约 450 px（10 行 + 两个列头 + 原因块）。宿主给的 `maxHeight` 比这小时，卡片里先收掉“原因块”和底行，再不够就让宿主滚动。
7. 这份文档改了 token，要同时改 `lol-app-tokens.css` 和 `plugins/lol/app/tokens.css`；样张里内联的那份用 `docs/design/` 下的文件重新生成（或手工同步）。
