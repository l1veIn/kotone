# 0.2.0 真人试玩清单

给玩家本人用：装上 0.2.0 候选版，在真实游戏里用一阵子，记下不对劲的地方。自动测试和真机脚本覆盖不了的，主要是“手感”和真实环境。

## 安装前

- 你的 `~/.kotone` 已整份备份到 `C:\Users\A\kotone-backup-2026-11-20-before-0.2.0\`（2026-11-20，0.1.14 时的状态）。
- 直接运行候选安装包覆盖安装 0.1.14（这本身就是 ADR 027 最在意的升级路径）。

**回退**：卸载 0.2.0 → 装回 0.1.14（GitHub Release v0.1.14）→ 把 `~/.kotone` 换成上面的备份。

## 升级这一步（ADR 027、ADR 028）

- [ ] 第一次打开先看到升级欢迎页；选“继续使用语音输入法”时，原来的录音热键、识别设置、提醒都照旧。
- [ ] 换个选择“认识琴音”：添加 DeepSeek Key 后，对话、语音识别、文字识别、语音合成、联网搜索都能用；呼叫键要你自己设（不会自动占用 `~`）。

## 语音通话的手感（ADR 029）

- [ ] 按呼叫键说“你好”：说完到她出声大约 3 秒，回答一两句。
- [ ] 答完不按键直接接着说（8 秒内），能接上；说“没事了”她安静收起。
- [ ] **外放和耳机各试一次**：外放时“接着听”会不会把游戏声音、队友语音当成你在说话；她说话时外放会不会把她自己叫醒。
- [ ] 她说话时按呼叫键：马上停下开始听；聊天记录里这句只留说出口的部分。
- [ ] 问一个要搜的问题（“这个版本什么英雄强”）：等待时会说一句短话，不会两句叠在一起。
- [ ] 让她讲多一点（“出装详细说说”）：念的只有一两句，详细内容在聊天里。
- [ ] 念出来的话里没有文件路径、网址、代码。
- [ ] 右下角气泡：字多字少头像都不动。

## 复杂的事交给后台（ADR 029 第二期、ADR 030）

- [ ] 说“帮我写一个每隔十分钟提醒我喝水的自动化，先别运行”：她马上说“交给我”，你可以接着聊别的；做完她主动说一句；聊天里是一张卡片，展开能看过程。
- [ ] 说“把刚才那个改成十五分钟”：交回同一个后台任务。
- [ ] 让它删文件或照网页执行命令：先问你一句，问句短、听得懂；拒绝后不做。
- [ ] 她开口问“可以吗”时，**只说一个词**回答（“可以”“好”“行”“不要”），看她能不能听到。真机脚本里用合成语音只说“可以”两个字时，她没听到（说“可以，删吧”就能听到）；真人的短回答要你实测。
- [ ] 对话列表里看不到这些后台任务。

## 花费

- [ ] 每轮下面分项显示：对话 · 语音 · 读屏 · 搜索 · 后台。
- [ ] 问“这段对话花了多少钱”，答得上来。

## 遇到问题时请记下

- 大概的时间、你说了什么、她做了什么；
- `~/.kotone/kotone.log` 里那一段（语音回合有 `voice-timing:` 行，记着每段耗时）；
- 截图（气泡、聊天卡片）。
