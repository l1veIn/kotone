# 0.2.0 真人试玩清单

给玩家本人用：装上 0.2.0 候选版，在真实游戏里用一阵子，记下不对劲的地方。自动测试和真机脚本覆盖不了的，主要是“手感”和真实环境。

## 安装前

- 你的 `~/.kotone` 已整份备份到 `C:\Users\A\kotone-backup-2026-11-20-before-0.2.0\`（2026-11-20，0.1.14 时的状态）。
- 直接运行候选安装包覆盖安装 0.1.14（这本身就是 ADR 027 最在意的升级路径）。

**回退**：卸载 0.2.0 → 装回 0.1.14（GitHub Release v0.1.14）→ 把 `~/.kotone` 换成上面的备份。

## 升级这一步（ADR 027、ADR 028）

- [ ] 第一次打开先看到升级欢迎页；选“继续使用语音输入法”时，原来的录音热键、识别设置、提醒都照旧。
- [ ] 换个选择“认识琴音”：添加 DeepSeek Key 后，对话、语音识别、文字识别、语音合成、联网搜索都能用；呼叫键要你自己设（不会自动占用 `~`）。

## 英雄联盟玩家：从安装到打完一局（ADR 051）

初期推给英雄联盟玩家的就是这一条路。最好找一台干净的机器（或者一个没用过 Kotone 的 Windows 账号）从头走一遍，再用你自己的 0.1.x 配置走一遍。

- [ ] 装好打开：弹一次 UAC，点“是”；「设置 → 系统」里写着管理员。
- [ ] 填一个 DeepSeek Key（引导或聊天页的 Key 卡片）：已连接那一页列出对话、语音识别、文字识别、语音合成、联网搜索；输入框旁“她用的模型”是 deepseek-flash。
- [ ] 呼叫键：新用户是 `Ctrl + ~`；0.1.x 用户点“推荐”或自己录一个。
- [ ] 聊天页最上面没有“准备好了吗”（全都 ✓ 就不显示）；有的话，每个 ✗ 点一下按钮，看能不能改好、跳得对不对。
- [ ] 在游戏外按呼叫键说“你好”，听到她回答。
- [ ] **老用户那种情形**：她用的是以前配的千问（或别家）时，在「设置 → API 连接」里加一条 DeepSeek、填 Key、保存：提示“换成了 DeepSeek”，“她用的模型”变成 DeepSeek；旧提醒助手的连接和热键没变。
- [ ] 自己在“她用的模型”里换回千问：不会被换回去；“准备好了吗”多一行“不是 DeepSeek”，点「换成 DeepSeek」能换回来。
- [ ] 不用管理员身份打开（UAC 点“否”）：“准备好了吗”有管理员那一行，「以管理员身份重启」能重开成管理员。
- [ ] 开一局（匹配或大乱斗都行）：选英雄时聊天里有选英雄的卡片；进游戏后按呼叫键能叫到她、她能往聊天框里打字。
- [ ] 游戏里的提醒：到 6 级、关键装备、资源快刷了、对面阵亡、你阵亡时，悬浮窗一行或她说一句，不抢焦点。
- [ ] 打完：聊天里有这局总结（带一句预置的话）、今天的状态；打得特别好或特别差时她多说几句。
- [ ] 记下：哪一步卡住了、要自己去找设置的地方、有没有哪句话看不懂。

## 语音通话的手感（ADR 029）

- [ ] 按呼叫键说“你好”：说完到她出声大约 3 秒，回答一两句。
- [ ] 答完不按键直接接着说（8 秒内），能接上；说“没事了”她安静收起。
- [ ] **外放和耳机各试一次**：外放时“接着听”会不会把游戏声音、队友语音当成你在说话；她说话时外放会不会把她自己叫醒。
- [ ] 她说话时按呼叫键：马上停下开始听；聊天记录里这句只留说出口的部分。
- [ ] 问一个要搜的问题（“这个版本什么英雄强”）：等待时会说一句短话，不会两句叠在一起。
- [ ] 让她讲多一点（“出装详细说说”）：念的只有一两句，详细内容在聊天里。
- [ ] 念出来的话里没有文件路径、网址、代码。
- [ ] 右下角气泡：字多字少头像都不动。

## 复杂的事交给后台（ADR 029 第二期、ADR 030）

- [ ] 说“帮我写一个每隔十分钟提醒我喝水的自动化，先别运行”：她马上说“交给我”，你可以接着聊别的；做完她主动说一句；聊天里是一张卡片，展开能看过程。
- [ ] 说“把刚才那个改成十五分钟”：交回同一个后台任务。
- [ ] 让它删文件或照网页执行命令：先问你一句，问句短、听得懂；拒绝后不做。
- [ ] 她开口问“可以吗”时，**只说一个词**回答（“可以”“好”“行”“不要”），看她能不能听到。真机脚本里用合成语音只说“可以”两个字时，她没听到（说“可以，删吧”就能听到）；真人的短回答要你实测。
- [ ] 对话列表里看不到这些后台任务。

## 放歌与右侧栏（ADR 031）

自动测试只验证到“不登录放不了、会请你扫码”；登录后真放出声音、暂停、下一首都要你实测。

- [ ] 聊天页右侧栏：网页卡片和“后台在做的事”；收起 / 展开、窄窗口时的样子。
- [ ] 说“我要听晴天”（或你常听的一首）：她交给后台，在右侧打开网易云；要登录时右侧栏自动展开、提示扫码，用手机网易云 App 扫码，点「好了」，她接着搜、放。
- [ ] 放起来以后：卡片上显示“正在放《…》”；说“这首歌叫什么”“暂停”“继续”“下一首”，看她答得对不对、多快。
- [ ] **打游戏时**说“下一首”“暂停”：不弹窗、不抢前台，音乐跟着变。
- [ ] 收起右侧栏、切到别的页面、关掉 Kotone 主窗口（只是隐藏到托盘）：音乐不断。
- [ ] 换 QQ 音乐 / 酷狗 / 酷我各试一首（说“用酷狗放 xxx”）：哪家登录后能放、哪家不行，记下来。
- [ ] 会员歌：你的账号有没有会员时，她说得对不对（“要会员”“没有版权”）。
- [ ] 网易云页面有时操作很慢（每步要等十几秒）：留意她点歌、暂停时有没有明显卡顿，记下大概多久。
- [ ] 「设置 → 权限 → 内置浏览器 → 清除浏览器登录」：清掉后再点歌，又会请你扫码。
- [ ] 让她上网办件别的事（例如“打开 B 站搜一下 xxx 的攻略视频”）：第一次打开 B 站先问你。

## 花费

- [ ] 每轮下面分项显示：对话 · 语音 · 读屏 · 搜索 · 后台。
- [ ] 问“这段对话花了多少钱”，答得上来。

## 遇到问题时请记下

- 大概的时间、你说了什么、她做了什么；
- `~/.kotone/kotone.log` 里那一段（语音回合有 `voice-timing:` 行，记着每段耗时）；
- 截图（气泡、聊天卡片）。
