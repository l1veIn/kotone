# 提醒助手

琴音是屏幕前用户的助手。到时直接说简短正文，例如“打野有闪了”“该打小龙了”；不套称呼或开场白，不会替你向其他人喊话，也不会自行添加战术安排。

「设置 → 提醒助手」分为「待办提醒」和「提醒设置」两个分页：前者创建和管理提醒，后者配置 AI 连接、独立助手热键、交互模式和提醒方式。切换分页会保留尚未提交的文字草稿。助手使用已有语音识别运行时；连接统一在「设置 → 高级 → API 连接」管理，文字处理和提醒助手页均有入口。默认热键为空，先设置一个不与语音输入或其他全局动作冲突的键。助手的交互模式独立配置，默认为对讲机；更改它不会改变游戏语音输入的模式。提醒默认同时使用语音与弹幕，也可改成其中一种。

## 创建和管理

先启动 Kotone 的语音运行时，再使用助手热键，或「创建提醒」右上角的语音输入按钮。按钮旁显示已配置的助手快捷键；未绑定快捷键时仍可使用按钮。默认对讲机模式下，按住说“五分钟后提醒我喝水”，松开结束；系统保留句尾宽限后完成识别。识别文本送到所选 AI 连接，模型通过受限的 `voice_reminder` / `danmaku_reminder` 工具表达计划，由本机校验并保存。助手不会把这句话发送到游戏聊天框。

| 助手交互模式 | 操作与提交 |
| --- | --- |
| 对讲机（默认） | 按住说话，松开结束，识别完成后提交给助手 |
| 录音笔 | 点按开始，再按结束，查看只读预览并确认后才提交给助手 |
| 说一句就走 | 点按开始，静音后结束并提交；再按热键可手动结束 |

助手仅提供上面三种模式。旧版助手的独奏配置会兼容为对讲机；普通游戏语音输入仍可使用独奏模式。按钮发起的录音在离开页面或窗口失焦时取消，避免麦克风遗留；按钮只控制自己发起的会话，不会结束或提交游戏输入。

录音笔的确认是提交提醒请求，不会发送游戏消息。助手与游戏语音输入共用识别资源；取消后的迟到结果不能新增提醒。

助手指令不写入左侧「历史记录」，也不保存历史音频或评测录音。「待办提醒」里的「最近记录」仅展示提醒自身的已提醒、失败、取消或错过状态，默认折叠。

录音、预览或处理期间，请先结束或取消当前输入会话，再修改热键或交互模式。

「待办提醒」支持输入文字创建提醒、查看倒计时和取消提醒。文字入口不要求启动语音运行时，仍需配置可用的 AI 连接。语音引擎、声音、音量、语速与输出测试都在「提醒设置」。

当前支持一次性、相对时间的提醒：延迟 1 秒至 7 天，每次最多 8 条，待投递最多 100 条，每条正文最多 300 个字符。不执行 AI 返回的任意代码或系统命令。服务失败、超限或没有合法的提醒工具参数时会报错；创建完成后，以列表中显示的内容和到期时间为准。

## 语音播报

默认使用「Windows · 系统语音」，直接调用系统已安装的 SAPI 声音，不需要下载任何 Kotone TTS 模型。中文声音是否可用取决于 Windows 已安装的语音包。新配置和缺少语音引擎字段的旧配置使用系统语音；已有显式选择的引擎会保留。

Kokoro 本地中文语音是可选项。选择该引擎后，可手动下载约 147 MB 的量化模型，安装后离线播报，无需 GPU 或额外服务。下载过程中可查看进度和取消；下载、校验或安装失败会保留原因，修正网络或存储问题后可以重试。浏览器界面预览会明确显示模型未安装，并禁用下载按钮；实际下载和播报请在桌面应用中进行。

Kokoro 提供三种中文女声：`kokoro:zf_001`（中文女声 001）、`kokoro:zf_003`（中文女声 003）和 `kokoro:zf_017`（中文女声 017）。声音的选择独立于 Windows 系统声音；切换引擎不会覆盖另一个引擎保存的选择。推理使用 2 个 CPU 线程，在首次播报时才加载模型，空闲 60 秒后释放；再次使用时会重新加载，因此首次播报可能稍慢。

两种引擎均使用系统默认音频输出设备，支持音量和语速设置。

选中的模型未安装、加载失败或播报失败时，会尝试弹幕，并在提醒记录中保留失败原因；不会把尚未完成的语音标记为成功。提醒和测试共用输出锁，避免彼此重叠；已有提醒正在输出时，测试按钮会提示稍后再试。「停止播报 / 弹幕」会停止当前提醒或测试，包括等待麦克风结束的输出，并清除当前弹幕；这次主动停止不会再触发备用弹幕，也不影响后续待办提醒。切换引擎后仍可停止先前的播报。

## 到期行为

提醒保存在本机 `~/.kotone/reminders.json`。停止 ASR 运行时后，应用仍开着就会继续调度；退出 Kotone 后不会在后台响铃，也不会唤醒关机的电脑。

重启时，逾期不超过 120 秒的待投递提醒会补投递；更早的标记为“已错过”。如果应用在投递中崩溃，该条恢复为失败，不自动重复播报。列表保留投递、失败、取消或错过的状态，避免把“已保存”误认为“已听到”。

语音与麦克风互斥：开始收音会中断正在播放的提醒，避免识别到自己的播报；到期时若正在录音，语音最多等待 30 秒，之后尝试弹幕提示。语音不可用时也会尝试弹幕，并保留失败信息。

弹幕通过置顶、点击穿透的桌面窗口显示，适合窗口化或无边框全屏。**独占全屏游戏无法使用弹幕提醒，请将游戏切换为无边框全屏或窗口化；保持独占全屏时可使用语音提醒。** 弹幕设置和测试按钮旁常驻显示这一限制，检测到独占全屏时也会明确报告失败，不冒充已显示成功。可先在目标游戏的实际显示模式下测试两种输出。

## 漂浮弹幕

弹幕是一条从屏幕右侧滑向左侧的文字，默认位于屏幕上方，没有背景底板；透明窗口不抢焦点，鼠标操作穿透到下方应用。它不会发送到游戏聊天框，也不会改变鼠标或键盘的操作目标。

实现使用独立的 Tauri WebView2 透明窗口，投递时覆盖当前前台应用所在的显示器。原生窗口设置置顶、不激活和忽略鼠标事件，页面也禁用指针事件；Svelte 负责文字与表情排版，Web Animations API 使用 `translate3d` 执行水平滑行。弹幕结束后隐藏窗口。

在「提醒助手 → 提醒设置 → 弹幕」中可设置：

| 选项 | 范围与默认值 |
| --- | --- |
| 漂浮速度 | 40–600 CSS 像素/秒，默认 160；数值越大移动越快 |
| 文字大小 | 16–72 CSS 像素，默认 32 |
| 距顶部 | 0–2160 CSS 像素，默认 120；可拖动滑块或直接输入整数，0 表示贴近屏幕顶部 |
| 文字颜色 | 白色、霓虹青、樱粉、暖黄或自定义颜色，默认白色 |
| 琴音表情前缀 | 纯文字、招手、加油、提醒、惊讶，默认纯文字；表情以小图标随文字移动 |

距顶部以弹幕内容框的上边缘为准，和字号一样使用逻辑像素，随 Windows 显示缩放。设置保存后对下一条提醒及「测试弹幕」生效；若设置位置超出当前屏幕，会按实际文字和表情高度限制在可见区域内，不修改保存值。窗口尺寸变化时重新计算位置，不重启动画。旧配置没有位置字段时采用 120 像素默认值。

每条按实际文字宽度与屏幕宽度计算滑行时间。超过 100 个字符时，字号最多为 24 像素；每条最多滑行 45 秒，必要时临时加快速度，正文不会截断。旧配置的 `danmakuDurationMs` 仅为兼容保留，新弹幕以速度设置为准。窗口恢复时沿用本次弹幕已走过的时间，不从右侧重新播放；滑出屏幕后结束当前弹幕，原生窗口另有 60 秒清理兜底。

## 数据边界

默认本地 ASR 不上传音频；如果你选用在线 ASR，助手录音也会经过该识别服务。AI 解析会把输入的提醒文本和工具说明发送到选定连接。Kokoro 模型下载需要网络；下载完成后的 Kokoro 合成、Windows SAPI 播报、保存、倒计时、取消和弹幕都在本机完成，不向云端 TTS 发送提醒文本。完整说明见 [隐私政策](../PRIVACY.md)。
