# 琴音（Kotone 内置 Agent，原“陪玩”“提醒助手”）

琴音是 Kotone 内置的游戏 Agent（[ADR 014](adr/014-game-agent-harness.md)、[ADR 015](adr/015-agent-scope-and-stack.md)）。打开 Kotone 先看到的就是和她的聊天页（[ADR 028](adr/028-game-companion-interaction.md)）。你可以在聊天页里打字，也可以**呼叫琴音**（按一下呼叫键，默认 `~`；点聊天页的“呼叫琴音”；或喊唤醒词）说一句话，或按一条“交给 AI 的一句话”的**快捷指令热键**——都是**同一段对话**。琴音会多步调用工具，直到把事情做完：

| 你说 | 琴音可能做的 |
| --- | --- |
| “五分钟后提醒我打小龙” | 设一条“延迟 + 播报”的提醒（在「自动化 → 进行中」可以取消） |
| “帮我跟队友说先别打龙”“把这句翻译成韩文发出去” | 按当前游戏配置打进聊天框并**直接发送**（关掉“自动发送”后只打进去）；替你发了什么记在「自动化 → 记录」 |
| “队友说了什么”“这句韩文什么意思” | 读屏识别聊天，游戏内用语音或弹幕回答，聊天窗口里用文字回答；读不清的如实说 |
| “帮我做一个每秒按 Q 的自动化” | 写一段沙盒程序，**先请你确认**再试运行，满意后保存 |
| “用我保存的连按 Q” | 直接运行已保存的自动化（默认全部交给 AI，最多 30 个，可以逐个隐藏） |
| “打开英雄联盟”“切到游戏” | 用游戏配置里你填的启动路径打开（先问你），或切到游戏窗口 |
| “帮我找找背包里有没有 xxx”“帮我答完这几道题” | 一边看一边操作：截图看画面，点鼠标、按键，做完再看一眼（见下面“操作游戏”） |

**游戏内（快速模式）**（[ADR 029](adr/029-voice-call-and-background-tasks.md)）：按呼叫键、喊唤醒词或按快捷指令时，琴音记下你开口那一刻的画面（要看时再读，不再每次先读屏），不思考，一两句话回答，边写边念；和聊天窗口同一段对话、同一小套马上出结果的工具，每轮最多 10 步、2 分钟；出错、超时也会说出原因。琴音还在忙时再说一句算**插话**：正在执行的那一步做完后，它就会看到这句话。

**复杂的事她在后台做，做完告诉你**（ADR 029 第二期）：写或改自动化、一边看一边操作游戏、读网页整理资料、下载模型、一次改一串设置、同传这类慢的、要好几步的事，她会说“交给我，好了告诉你”，然后在后台做，你可以接着和她聊别的；做完她主动说一句结果（你用嘴说的就念出来，打字的就写在聊天里；她正在说话或你正在说话时等一下再说）。聊天里是一张卡片：“写喝药脚本 · 进行中 · 第 3 步 [停止]”，展开能看一步步做了什么。要改刚才那件事就直接说（“改成三成血”），她会交回同一个接着做。后台要你确认的事（运行新写的程序、操作游戏、改设置、下载）由她来问：用嘴说的就开口问，打字的就在卡片上点。最多同时做 3 件；说“停下”或按停止热键会一起停；Kotone 关掉时没做完的，下次打开卡片上显示“中断了”，点“继续”接着做。后台的费用记在派它出去的那一轮下面（“后台 ¥…”）。

**后台可以帮你操作电脑上的程序和文件**（[ADR 030](adr/030-subagent-shell-and-files.md)）：调用第三方工具的命令行（例如“用 BetterGI 把今天的日常跑了”）、整理文件、改游戏的配置文件。只有后台能这样做，和你说话的她自己不能。她自己的草稿和下载的东西放在 `~/.kotone/agent/files/`。几条规矩：
- 后台只做你自己说的事：只有你亲口说、亲手打字的那一句能派活，你的原话会原样交给它。
- 后台读过网页、聊天、屏幕或别处的文件之后，动手（执行命令、改你电脑上的文件）前先问你一句“我要……，要我动手吗？”。你同意后，这件事剩下的步骤不再因此问；你追加要求时重新算。
- 删除文件、改注册表、格式化、关机、改用户账户或系统服务、`Invoke-Expression` 这类每次都问。模拟键盘鼠标的命令不让用：打字和操作游戏有专门的工具，游戏不在前台不打字、按 Esc 停照旧。
- 改你电脑上的文件前先备份到 `~/.kotone/agent/backups/`。游戏开着时不改它的目录；第一次改某个游戏的目录会先说封号风险。Kotone 自己的设置、记忆、技能不能这样改。
- 按 Esc、说“停下”、点卡片上的停止，后台正在跑的命令连同它启动的程序一起结束；你让它启动并一直开着的程序（例如 BetterGI）正常做完不会被关掉。
- 「设置 → 权限」里有“电脑（命令和文件）”一组，可以把执行命令、写文件设成每次询问或禁止。经 MCP 连进来的外部 Agent 拿不到这些工具。

**对话气泡**：用语音和琴音说话时，游戏所在屏幕的右下角会出现带琴音头像的气泡，显示她在听（和听到的话）、在想 / 正在看屏幕、在说的话、在等你回答（倒计时条）或出错原因；念完再停几秒自动收起。气泡不挡鼠标、不抢焦点；独占全屏时显示不出来，只听语音。位置、离边缘的距离、回答是否同时用弹幕在「设置 → 她怎么回答 → 对话气泡」。气泡只属于角色、悬浮窗只属于语音输入：关掉气泡后只用语音和弹幕回答，不再借用悬浮窗（ADR 028）。

**语音唤醒**（默认关）：在「设置 → 怎么叫她 → 语音唤醒」开启并下载约 5 MB 的唤醒模型后，语音识别准备好时（在线识别打开 Kotone 就是；本地识别要先启动）说“琴音琴音”（可改成“你好琴音”）就能叫醒琴音，不用按键。喊完停一下，琴音会先应一声“嗯？”或“我在”再听；连着往下说、或在她应答时开口，她就直接听你说。说完停顿约 0.7 秒自动提交，5 秒没开口就安静结束。指令和呼叫琴音一样进同一段对话、按游戏内处理、用语音回答。开启后麦克风常开（任务栏会显示麦克风在用），唤醒词只在本机检测、不上传；建议戴耳机，外放时游戏声音可能误唤醒，可以调低灵敏度。有会话在进行时（比如正在用语音输入发聊天）不会被唤醒。

**执行中先接一句**：游戏里交给琴音后 1.2 秒还没出声，她会先说一句“我看看 / 稍等哈”，免得干等（「设置 → 权限」可关）。你在聊天窗口和她说着话、又在游戏里插了一句时，这一轮的回答也会用语音播出来。

**语音追问**：用语音叫她时，需要你做决定或补充信息，她会直接问一句（例如“要我帮你下载文字识别模型吗？”），问完不用再喊唤醒词，直接回答就行（默认等 8 秒）；你的回答接着交给她正在做的事，不会变成新的一轮。语音入口和聊天窗口用同一套工具（马上出结果的一小套；慢的、多步的交给后台），每轮最多 10 步、2 分钟。

**帮你配置 Kotone**：只要配好一条 AI 连接（比如 DeepSeek），剩下的可以交给琴音——点起手提示“帮我配置 Kotone”，或直接说“把悬浮窗放到右下角”“呼叫琴音的键改成 F9”。琴音先查设置说明（每项是什么、能填什么、怎么生效），每次改动都先问你；需要重启语音识别或重启 Kotone 才生效时会告诉你，并问要不要现在重启。只配一个 DeepSeek 就能用全部功能：说“帮我把 Kotone 配置好，用 DeepSeek 就行”，她会读内置的《Kotone 配置》技能，把语音识别、文字识别换成 DeepSeek（语音合成默认就是）。需要别的服务商的 Key 时，聊天里会弹出一个只给你看的输入框，Key 直接存进系统凭据库，不进聊天记录、不发给 AI。琴音不能改自己的权限规则。她改过的设置在聊天的工具卡片下面显示“改了 xxx →”，点一下就跳到那个设置。

**聊天窗口**：适合要来回商量的事（设计自动化、改设置）。这时前台是 Kotone 自己，琴音要看游戏画面、运行自动化或替你发言之前，会先切到游戏窗口。对话保存在本机 `~/.kotone/agent/`，可以新建、切换和删除。

**需要 AI 连接**：选一家主流大模型、填好 API key 就能用，不需要自检。想确认能不能连上，在「设置 → API 连接」点“测试连接”（读一次服务商的模型列表，不花 token）。在聊天输入框右下角可以直接换模型（清单来自服务商的模型列表）和琴音的权限。还需要一个**文字识别模型**（「设置 → 模型 → 文字识别」，推荐本地的 PP-OCRv5 中英日包）；选的是在线模型时，**每次读屏都会上传截图**。在「设置 → 权限」关掉“游戏内交给琴音”（`agent.inGame`）后，热键回到旧的单次陪玩：调一次 AI，在提醒 / 打字 / 回答里三选一。

**权限**：每个工具一条规则（允许 / 询问 / 禁止），整体模式有默认、全部允许、只读三种。默认直接执行：读状态、截图识别、播报、提醒、替你打字、运行已保存的自动化、停止、切换游戏窗口；默认先问：改设置、删除、下载模型、打开 / 关闭游戏、退出 / 重启 Kotone、管理员权限、开机自启，以及 **AI 新写的程序第一次运行**。聊天窗口里在对应的工具卡片上点「允许 / 本段对话都允许 / 拒绝」；用语音叫她（呼叫琴音、唤醒词）时，她会直接用语音问“这一步会……，可以吗？”，接着不用唤醒词听你回答几秒：说“好 / 可以 / 行”算同意，“不要 / 算了”算拒绝；没听清或没回答，就请你到琴音窗口里点（窗口里的按钮一直可以点）。停止当前这一轮时，未回答的询问按“拒绝”处理。

**安全**：屏幕上读到的文字和窗口标题一律只当数据——即使聊天里有人打“忽略以上指令”，琴音也只当成别人说的话，不会因此越过权限。自动化程序在沙盒里运行（没有文件、网络、进程），游戏配置关掉“允许自动化输入”后不会对那个游戏运行；“停下”随时可以停：停止热键（默认 Ctrl+Shift+F12）、托盘「停下」、说“停下”，她操作游戏时也可以按 Esc。打开游戏只用你在游戏配置里填的启动路径，关闭游戏只发普通的关闭请求，从不强制结束进程。

**操作游戏**（[ADR 019](adr/019-game-computer-use.md)）：每次画面都不一样、事先写不了程序的事，琴音一边看一边做——`game.look` 截一张游戏窗口（只截游戏、不截桌面），屏幕上的文字框出来并编号；她决定点哪里，用 `game.act` 一次做 1–20 步（点击、拖动、滚轮、打字、按键、按住走路、转视角……），做完自动再看一眼，判断有没有生效。

- **先问你**：每段对话第一次在某个游戏里操作前，问一次“会在游戏里操作鼠标键盘，可以吗？”（聊天窗口点按钮，语音里说“好 / 不要”）。在「游戏适配」把这个游戏的**“让琴音操作”**设成“一直允许”就不再问，设成“不允许”她就不动；“允许自动化输入”关掉时也不动。
- **哪些游戏能让她操作，你自己判断**：有反作弊的游戏能不能接受模拟点击，Kotone 不替你区分；不想让她碰的游戏设成“不允许”。
- **按 Esc 就停**：她操作时右下角气泡显示“正在操作 · 按 Esc 停止”和当前这一步（气泡关着也显示）。按一下 Esc 她立刻停下、松开按住的键并结束这一轮，不会自己重试；这个 Esc 被 Kotone 拦下，不会传给游戏（她自己按的 Esc 照常有效）。你自己动键盘鼠标不会打断她，但她点击前会移动鼠标，操作时最好别抢鼠标。
- **其他停法**：停止自动化热键（默认 **Ctrl+Shift+F12**）、托盘菜单的“停止自动化”，或者用语音说“停下”（先喊唤醒词），效果和 Esc 一样。
- **其他保护**：要点的位置被别的程序窗口盖住就不点；游戏窗口尺寸变了，旧坐标作废、先重看；游戏不在前台最多等 5 秒；独占全屏截到的是纯色画面，会请你改成无边框窗口；自动化程序在运行时不操作，操作时自动化不启动。
- **步数**：用上操作游戏后，这一轮最多 30 步、5 分钟（平时语音入口 10 步、2 分钟）；批量、重复的事（例如把 20 件装备逐个分解）她会改写成自动化程序一次跑完，做成后也可以问你要不要存成自动化。
- **需要能看图的模型**（例如 DeepSeek）；截图会发给你选的 AI 服务商。上下文里只保留最近 3–5 张截图（攒到 6 张时一次丢掉最早的 3 张，免得每次都打断缓存）。

**替你跟队友说话（游戏语音）**（[ADR 020](adr/020-voice-into-game-chat.md)，默认关）：说“琴音，跟队友说我去拿龙了”，琴音的声音会从游戏语音里出来。原理是一个虚拟麦克风：琴音的声音和你的麦克风一起送进 VB-CABLE 的 “CABLE Output”，游戏或语音软件的麦克风选它就行。在「设置 → 她怎么回答 → 游戏语音」设置，或者直接让琴音帮你弄：

- **自动安装 VB-CABLE**：点“自动安装”（或对琴音说“帮我装虚拟麦克风”），Kotone 从官网下载原版安装包、核对哈希后静默安装，Windows 会弹一次管理员授权；少数电脑要重启后才能用。VB-CABLE 是 VB-Audio 的捐赠软件（https://vb-cable.com），Kotone 的安装包里不带它。
- **开启后**：你的麦克风实时转进虚拟麦克风（延迟约 0.2 秒以内），琴音说话时你的声音自动压低一半；可以关掉“混入我的麦克风”只送琴音的声音。**Kotone 没运行时队友听不到你**，记得在游戏里改回原来的麦克风。
- **只认 Windows 默认麦克风的游戏**（例如 PUBG）：点“设成 CABLE Output”把 Windows 默认麦克风改成它，用完点“改回原来的”。改的是系统设置，Discord、会议软件也会跟着变。
- **试一下**：“测试音”放 1 秒“嘀”再录回来确认通了；“说一句”让琴音对队友说一句测试的话。
- 琴音只把你让她“跟队友说”的话送进游戏，平时回答你的话、提醒不送；每次替你跟队友说话、安装、改 Windows 默认麦克风都会先问你（可以在权限里改成直接执行）。
- 需要能拿到声音的语音引擎（DeepSeek、Kokoro 或在线语音）；系统语音直接出声，送不进游戏。
- 语音唤醒和语音输入不要选 CABLE Output 当麦克风，否则琴音会听到自己。

**帮你听懂队友（同传）**（[ADR 021](adr/021-hear-teammates.md)）：说“帮我盯着队友，听到英语就翻给我”，琴音会交给**后台**去听——它只录你指定的程序（游戏或 Discord；没说就录当前前台的游戏），录不到你自己的麦克风和琴音的声音。每听到一句，本地切句、本地识别（SenseVoice：中英日韩粤，需要在「设置 → 模型 → 语音识别」下载 SenseVoice 多语言模型），在后台翻译、用弹幕显示。气泡角落显示“正在听队友”。

- 说“停止同传”，或按停止自动化热键、托盘“停止自动化”、语音“停下”，后台的同传和它的录音一起停；Kotone 退出也会停。音频只在内存里处理，不存盘。
- 后台默认用和琴音同一个模型，想更快更省可以在设置 `agent.subagents.model` 填一个快的模型（也可以让琴音帮你改）。
- 开始听之后才启动的程序录不到，重新说一次“开始听”就行。

**她是谁、记得什么、会什么**（[ADR 022](adr/022-sessions-memory-soul.md)）：在「琴音」页的分页里——

- **角色**（原“她是谁”，[ADR 025](adr/025-roles-wake-words-match-recap.md)）：可以换角色。每个角色有自己的名字、头像（≤ 2 MB）、性格（`SOUL.md`）、声音和唤醒词；关于你的记忆、游戏记忆、技能和设置所有角色共用，换角色不会忘掉你。内置琴音（默认）和社区二创角色大肥鱼、Claude大小姐（带自己的表情），自己建的角色没传头像时显示名字的第一个字；也可以新建自己的角色、导入 / 导出角色卡（Character Card V2 的 `.json`，别的软件也能读名字和设定）。换角色会开一段新对话；也可以直接跟她说“换成大肥鱼”。
- **唤醒词**（实验性）：每个角色可以有自己的唤醒词，默认是名字重复两遍（如“星野星野”；名字三个字以上就用名字本身）。语音唤醒页显示的就是当前角色的唤醒词，预置的“琴音琴音 / 你好琴音”只给琴音。只能用汉字、3–8 个字，推荐 4 个字；输入时会显示每个字的拼音，多音字可以选读音，唤醒模型不认识的字会提示换一个。合成声音实测和“琴音琴音”差不多（每个词 7–8 次里中 7–8 次，几分钟普通说话里没有误唤醒），真人声音和游戏背景音下还没测够，叫不醒时换回“琴音琴音”。
- **记忆**：关于你（`USER.md`）、她的笔记（`MEMORY.md`）、每个游戏的记忆（按键、地图、你的打法，玩这个游戏时才读）。她会自己记（“记住我用左手键位”），你也可以直接改、删。
- **技能**：agentskills.io 格式的技能包（一个文件夹，里面一个 `SKILL.md`），可以导入别人分享的，也可以打开文件夹拷给朋友；让她“把这套做法写成技能”时会先问你。
- 这些文件在 `~/.kotone/agent/workspace/`；写入前会检查有没有“忽略之前的指令”这类注入内容，有字数上限；改动在**下一段对话**生效。

**对局复盘**（默认开，「设置 → 权限」可关）：游戏一退出（玩了 3 分钟以上、这一局里叫过她或跑过自动化 / 提醒），琴音把这一局整理成几句复盘留在聊天里，学到的（按键、地图、你的打法、教训）合并进这个游戏的记忆（上限 4000 字，旧的会合并精简）。什么都没发生就不整理、不花钱。也可以让她“复盘一下刚才那局”。

**省钱：缓存与整理**（[ADR 024](adr/024-prefix-cache-compaction-usage.md)）：琴音的请求按 DeepSeek Harness 的做法组织（系统提示和工具清单一段对话里不变、新内容只往后加），DeepSeek 的前缀缓存基本都能命中，命中的部分便宜约 50 倍；实测同一段对话里命中率约 98%。对话太长时（默认约 6.4 万 token，「设置 → 用量」可改），她会把较早的部分整理成一份摘要，之后只看摘要和最近几轮——聊天里会出现一条“较早的对话已整理成摘要”，点开能看摘要，原来的消息都还在。

**联网查资料**（[ADR 026](adr/026-no-generic-rwx-deepseek-best-practices.md)）：游戏一两周一个版本，模型自己记得的出装、海克斯强化、英雄强度多半过时了。琴音遇到这类问题先 `web.search` 再答，说出依据，聊天里工具卡片下面列出来源（点开用浏览器看）；摘要不够时再 `web.fetch` 读一页（只能读搜索结果或你发来的链接）。用哪个搜索在「设置 → 模型 → 联网搜索」选：“DeepSeek 联网搜索”（每次成功的搜索或读网页 0.005 元，记进用量）或“不联网”；有 DeepSeek 连接时默认用它。网页由 DeepSeek 的服务器去读，碰不到你的电脑和局域网；网页内容只当数据。

**用 DeepSeek 时**（照 DeepSeek 官方「构建 Chatbot」指南）：每条消息带日期；新对话由 DeepSeek 起标题；内容审核默认开（「设置 → 权限」可关），没通过时撤回这次回答并说明；游戏里、聊天窗口里的思考强度可以分别设（实测速度差不多，默认跟服务商）。

**用量与费用**：聊天每轮下面显示输入 / 输出 token、命中缓存的比例和大概的费用；「设置 → 用量」看今天和本月花了多少（对话、整理、复盘、在线语音合成 / 识别、文字识别分开列）。费用是 Kotone 按 DeepSeek 官方价格表估的（分高峰 / 空闲时段），以 DeepSeek 后台账单为准。账本在 `~/.kotone/usage.jsonl`，只记数字，不记内容。

**快捷指令**（原“快捷消息”）：最多 8 条，每条一个热键，有两种：
- **交给 AI 的一句话**：提前写好一句话（如“帮我看看队友说了什么”），按下等于替你对琴音说了这句话，不经过语音识别，所以更快；
- **运行自动化**：选一个已保存的自动化并填好参数，按下就在当时的游戏窗口里直接运行，**不调用 AI**，也不需要 AI 连接。自动化的说明见[工具服务文档的“自动化”](tool-service.md)与 [ADR 013](adr/013-automation-domain-model.md)。

**游戏说明**：在「游戏适配」编辑游戏配置时可以写一段“陪玩说明”（例如“聊天在左下角，[队伍] 前缀是队友”），琴音每次都会看到；游戏适配写在这里，不为每个游戏写死规则。内置的英雄联盟配置自带一段说明。同一页还有“允许自动化输入”“让琴音操作”和“启动路径”三项。

**声音与弹幕**（默认提醒方式、语音引擎、声音、音量、语速、弹幕外观和预览、试听）在「设置 → 她怎么回答 → 声音与弹幕」。**呼叫键**默认是 `~`（「设置 → 怎么叫她」可以换或清空；0.1.x 升级用户默认没有，启用琴音时自己选）：按一下就在右下角气泡里听你说，说完自动交给她，她在听时再按一下立刻提交；没有“按住说话”，和语音输入的热键互不影响。

**自动化**（「自动化」页）是一个列表：每个自动化 ▶ 运行、■ 停止，点开看详情（做什么、参数、定时、最近的执行）。可以设**定时**（类似 crontab：每天几点、工作日几点、每小时、每隔几分钟或自定义 cron；本地时间，Kotone 没开时错过的不补）。内置一个“X 秒之后提醒我”。琴音临时设的提醒和程序排在最上面，也能停；最下面可以展开全部记录。

**游戏列表**（「游戏列表」页）：最上面是本机装的游戏和它们的图标（只读启动器记录，很快），可以直接打开；下面是每个游戏的配置（聊天键、词表、能不能让琴音操作、启动路径）。

## 语音入口

（0.1.x 升级用户的「提醒助手」页）语音识别准备好后（本地识别要先启动）使用助手热键，或页面里的语音按钮。按钮旁显示已配置的助手快捷键；未绑定快捷键时仍可使用按钮。默认对讲机模式下，按住说“五分钟后提醒我喝水”，松开结束；系统保留句尾宽限后完成识别。识别出的文字交给琴音（见上文）；这句话本身不会被发送到游戏聊天框，只有琴音按你的要求“替你发言”时才会打字。

| 助手交互模式 | 操作与提交 |
| --- | --- |
| 对讲机（默认） | 按住说话，松开结束，识别完成后提交给助手 |
| 录音笔 | 点按开始，再按结束，查看只读预览并确认后才提交给助手 |
| 说一句就走 | 点按开始，静音后结束并提交；再按热键可手动结束 |

助手仅提供上面三种模式。旧版助手的独奏配置会兼容为对讲机；普通游戏语音输入仍可使用独奏模式。按钮发起的录音在离开页面或窗口失焦时取消，避免麦克风遗留；按钮只控制自己发起的会话，不会结束或提交游戏输入。

录音笔的确认是把这句话交给琴音，不会发送游戏消息。陪玩与游戏语音输入共用识别资源；取消后迟到的识别结果会被丢弃。

助手指令不写入左侧「历史记录」，也不保存历史音频或评测录音。「自动化 → 记录」展示提醒与自动化的完成、失败、取消或错过状态及原因。

录音、预览或处理期间，请先结束或取消当前输入会话，再修改热键或交互模式。

聊天窗口的文字入口不需要语音识别，仍需配置可用的 AI 连接；提醒的倒计时与取消在「自动化 → 进行中」。语音引擎、声音、音量、语速与输出测试都在「设置 → 她怎么回答 → 声音与弹幕」。

提醒是一次性、相对时间的：延迟 1 秒至 7 天，正文最多 300 个字符，等待中与运行中的提醒和自动化合计最多 100 条。创建完成后，以「自动化 → 进行中」里显示的内容和到期时间为准。

## 语音播报

默认是「自动」：琴音的 AI 连接是 DeepSeek（且已保存密钥）时用 **DeepSeek 语音**（官方 `/v1/tools/tts`，声音海星 / 暗潮，复用这条连接的密钥），否则用「Windows · 系统语音」。DeepSeek 语音按字数计费（汉字算 2 个字符，每万字符约 1.5–3 元；一句 50 字左右的回答约 1.5 分钱），每次播报都会把要说的文字发给 DeepSeek，同一句话会复用缓存；它不支持调语速。不想用就在「通用 → 语音」选别的引擎：明确选了系统语音、Kokoro 或别的在线引擎后，不会再被“自动”换掉。系统语音直接调用系统已安装的 SAPI 声音，不需要下载，中文声音是否可用取决于 Windows 已安装的语音包。

Kokoro 本地中文语音是可选项。选择该引擎后，可手动下载约 147 MB 的量化模型，安装后离线播报，无需 GPU 或额外服务。下载过程中可查看进度和取消；下载、校验或安装失败会保留原因，修正网络或存储问题后可以重试。浏览器界面预览会明确显示模型未安装，并禁用下载按钮；实际下载和播报请在桌面应用中进行。

Kokoro 提供三种中文女声：`kokoro/zf_001`（中文女声 001）、`kokoro/zf_003`（中文女声 003）和 `kokoro/zf_017`（中文女声 017）；旧配置里的 `kokoro:zf_001` 写法照常可用。声音的选择独立于 Windows 系统声音；切换引擎不会覆盖另一个引擎保存的选择。推理使用 2 个 CPU 线程，在首次播报时才加载模型，空闲 60 秒后释放；再次使用时会重新加载，因此首次播报可能稍慢。

另有两个在线引擎（2026-11-15 起）：「在线 · OpenAI 兼容」（`/audio/speech`，绑定一条 API 连接，填合成模型与声音名）和「在线 · 火山语音合成」（豆包语音 HTTP 接口；App ID 与 Access Token 留空时复用语音识别里为火山填的那一套，需要在火山控制台为该应用开通语音合成）。连接、模型与声音在「设置 → 模型 → 语音合成」里配置，密钥只在系统凭据管理器。在线引擎每次播报都会把文字发给服务商。Edge 语音（非官方接口）不接入。

声音编号统一写成 `提供方/声音`：`system/<Windows 语音>`、`kokoro/zf_001`、`openai/alloy`、`volcano/BV700_streaming`、`deepseek/stella`。选中的声音找不到或属于另一个引擎时直接报错，不会悄悄换成别的声音。Kokoro 与在线引擎的合成结果按“声音 + 语速 + 文本”缓存在内存里（最多 64 条、约 8 分钟音频，退出即清空），同一句话第二次起直接播放；Windows 系统语音由系统直接出声，不缓存。唤醒应答（“嗯？”“我在”）和等待短句（“我看看”“稍等哈”……）另外存成文件（`~/.kotone/cache/tts/`，按声音区分，最多 200 个），重启后直接读文件，不用再请求在线语音、不再花钱；她的回答不存文件。

**游戏里叫她时，回答边写边念**（[ADR 029](adr/029-voice-call-and-background-tasks.md) 第六节）：模型写出一句就合成这一句、马上念，不等整段写完。DeepSeek 语音用官方的流式接口，其他引擎逐句合成、排队播放，系统语音逐句念。工具前那句（“我查一下”）也是这样念的。前面在播等待短句或提醒时，回答先合成好、等它播完再出声；她开口了就不再接等待短句；正在录音时不出声。她说话时按呼叫键（或喊唤醒词）立刻停下、开始听你说，聊天记录里这条回答只留她说出口的部分，后面标“（被打断）”。念完（真正播完）才开始“接着听”。每句的合成费用都记在这一轮下面。回复方式里没有语音时（只用弹幕）照旧整段显示；弹幕（关了对话气泡，或打开了“回答同时用弹幕”）显示整段回答。

两种引擎均使用系统默认音频输出设备，支持音量和语速设置。

选中的模型未安装、加载失败或播报失败时，会尝试弹幕，并在提醒记录中保留失败原因；不会把尚未完成的语音标记为成功。提醒和测试共用输出锁，避免彼此重叠；已有提醒正在输出时，测试按钮会提示稍后再试。「停止播报 / 弹幕」会停止当前提醒或测试，包括等待麦克风结束的输出，并清除当前弹幕；这次主动停止不会再触发备用弹幕，也不影响后续待办提醒。切换引擎后仍可停止先前的播报。

## 到期行为

提醒保存在本机 `~/.kotone/automation-runs.json`（与自动化共用调度，见 [ADR 013](adr/013-automation-domain-model.md)；旧版的 `reminders.json` 在第一次启动新版时导入未到期的提醒，原文件不改）。停止本地语音识别后，应用仍开着就会继续调度；退出 Kotone 后不会在后台响铃，也不会唤醒关机的电脑。

重启时，逾期不超过 120 秒的待投递提醒会补投递；更早的标记为“已错过”。如果应用在投递中崩溃，该条恢复为失败，不自动重复播报。列表保留投递、失败、取消或错过的状态，避免把“已保存”误认为“已听到”。

语音与麦克风互斥：开始收音会中断正在播放的提醒，避免识别到自己的播报；到期时若正在录音，语音最多等待 30 秒，之后尝试弹幕提示。语音不可用时也会尝试弹幕，并保留失败信息。

弹幕通过置顶、点击穿透的桌面窗口显示，适合窗口化或无边框全屏。**独占全屏游戏无法使用弹幕提醒，请将游戏切换为无边框全屏或窗口化；保持独占全屏时可使用语音提醒。** 弹幕设置和测试按钮旁常驻显示这一限制，检测到独占全屏时也会明确报告失败，不冒充已显示成功。可先在目标游戏的实际显示模式下测试两种输出。

## 漂浮弹幕

弹幕是一条从屏幕右侧滑向左侧的文字，默认位于屏幕上方，没有背景底板；透明窗口不抢焦点，鼠标操作穿透到下方应用。它不会发送到游戏聊天框，也不会改变鼠标或键盘的操作目标。

实现使用独立的 Tauri WebView2 透明窗口，投递时覆盖当前前台应用所在的显示器。原生窗口设置置顶、不激活和忽略鼠标事件，页面也禁用指针事件；Svelte 负责文字与表情排版，Web Animations API 使用 `translate3d` 执行水平滑行。弹幕结束后隐藏窗口。

在「设置 → 通用 → 声音与弹幕」中可设置：

| 选项 | 范围与默认值 |
| --- | --- |
| 漂浮速度 | 40–600 CSS 像素/秒，默认 160；数值越大移动越快 |
| 文字大小 | 16–72 CSS 像素，默认 32 |
| 距顶部 | 0–2160 CSS 像素，默认 120；可拖动滑块或直接输入整数，0 表示贴近屏幕顶部 |
| 文字颜色 | 白色、霓虹青、樱粉、暖黄或自定义颜色，默认白色 |
| 琴音表情前缀 | 纯文字、招手、加油、提醒、惊讶，默认纯文字；表情以小图标随文字移动 |

距顶部以弹幕内容框的上边缘为准，和字号一样使用逻辑像素，随 Windows 显示缩放。设置保存后对下一条提醒及「测试弹幕」生效；若设置位置超出当前屏幕，会按实际文字和表情高度限制在可见区域内，不修改保存值。窗口尺寸变化时重新计算位置，不重启动画。旧配置没有位置字段时采用 120 像素默认值。

每条按实际文字宽度与屏幕宽度计算滑行时间。超过 100 个字符时，字号最多为 24 像素；每条最多滑行 45 秒，必要时临时加快速度，正文不会截断。旧配置的 `danmakuDurationMs` 仅为兼容保留，新弹幕以速度设置为准。窗口恢复时沿用本次弹幕已走过的时间，不从右侧重新播放；滑出屏幕后结束当前弹幕，原生窗口另有 60 秒清理兜底。

## 数据边界

默认本地 ASR 不上传音频；如果你选用在线 ASR，陪玩录音也会经过该识别服务。琴音会把你的话、对话记录、工具说明、游戏说明、已保存自动化的名字与说明、游戏内读屏识别出的文字以及工具结果发送到选定的 AI 连接。Kokoro 模型下载需要网络；下载完成后的 Kokoro 合成、Windows SAPI 播报、保存、倒计时、取消和弹幕都在本机完成，不向云端 TTS 发送提醒文本。用在线语音引擎（DeepSeek——默认“自动”在琴音用 DeepSeek 连接时会选它——、OpenAI 兼容、火山）时，要播报的文字会发给对应服务商。完整说明见 [隐私政策](../PRIVACY.md)。
