# Privacy

Kotone is a local-first voice input tool with optional network speech recognition, AI text processing, and reminder creation. Whether audio or text leaves the computer depends on the features and connections you choose.

- The default X-ASR model and other local sherpa models process microphone audio on the computer. After model download, local recognition does not require a remote recognition service.
- If you select online ASR (OpenAI-compatible, Volcano, or iFlytek), audio is sent to that service for recognition. The provider's privacy policy and retention terms apply. Kotone's evaluation replay only uses local models and does not send the recorded corpus to online ASR.
- If you enable network AI polishing/translation, recognized text and the configured processing instructions are sent to the selected connection. Reminder creation sends your typed or recognized reminder request and tool instructions to the selected AI connection. Using a local compatible endpoint may keep these requests on-device; any onward network use depends on that server. These requests are part of the feature you enabled, not telemetry.
- Reminder speech defaults to installed Windows SAPI voices and requires no Kotone TTS model download. Kokoro is an optional local engine (about 147 MB downloaded only on request); an existing explicit engine choice is preserved. Model download contacts the selected download source/proxy; reminder text is not sent for TTS. No cloud TTS is used. Reminders address the person using Kotone. Their text can also appear in a mouse-transparent scrolling overlay visible to people or screen-sharing software viewing that display.
- Kotone does not automatically upload analytics or diagnostic events. It does not include advertising SDKs or account login.
- Kotone keeps a low-sensitivity diagnostic event log locally for troubleshooting and offline process analysis. It contains lifecycle stages, durations, outcomes, and stable error codes, but no recognized text, audio, hotwords, window titles, or process lists. This data leaves the computer only when the user explicitly exports and shares a diagnostic package.
- Network access is also used to check for updates and download speech models from the sources listed in the application. Users can choose the official source, a mirror, and an optional GitHub proxy. Those hosts receive normal connection metadata such as the client's IP address.
- Settings, game profiles, recognition history, optional evaluation recordings, reminders (`reminders.json`), connection metadata, and downloaded models are stored locally under `~/.kotone` by default. Models and history can use custom directories. Reminder records include their text, due time, output choices, and delivery status; they are not a cloud calendar or background Windows service.
- AI connection API keys are stored separately from public connection settings in Windows Credential Manager. Direct ASR credential fields and legacy engine/model options may be stored in local settings; do not treat a raw settings file as a shareable diagnostic report. Ordinary diagnostic packages exclude settings and credentials, and game profile/pipeline exports do not include managed connection keys.
- Recognition history can be disabled or cleared in the application. Evaluation recording and history audio are disabled by default. Assistant requests do not create recognition-history entries, history audio, or evaluation recordings; the resulting reminders are stored separately as described above.
- Uninstalling the application preserves `~/.kotone` so that large models are not lost accidentally. To remove local data, also remove any custom model/history directories and credentials saved in Windows Credential Manager as applicable. Exported files remain wherever you saved them.

Kotone injects the final text into the target window using Windows input APIs. Reminder delivery uses speech and/or an overlay to notify the user personally, not game text injection or messages to other people. The assistant voice entry requires the speech runtime to be started and has its own interaction mode, defaulting to push-to-talk. Typed requests do not require the speech runtime, and already scheduled reminders continue while the application remains open. Kotone does not read game memory, alter game files, or communicate directly with game servers.

See [diagnostics](docs/diagnostics.md) for diagnostic contents and [reminder behavior](docs/assistant.md) for persistence and delivery limits.
